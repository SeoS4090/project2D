# Kenney art packs

`Minimap/` and `PixelAdventureUI/` contain the supplied Kenney packs, including their original license and preview files.

Both packs are licensed under CC0 1.0. Attribution is optional; this project credits Kenney at [kenney.nl](https://kenney.nl). PNG assets under this folder import as point-filtered, uncompressed Sprites at 16 pixels per unit. Tile sheets are preserved as supplied for later slicing and palette setup.

The first Training Ground scene uses simple placeholder art for the player and target. Kenney pixel UI icons mark the player and target on the prototype minimap. The packs do not contain matching player or weapon sprites.
