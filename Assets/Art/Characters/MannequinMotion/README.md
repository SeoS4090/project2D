# 1.5등신 SD 마네킹 모션

장식 없는 액션 시험 캐릭터. 이전 `ActionBlockout`의 12개 핵심 자세와 원본을 보존하고 상세 모션을 별도 원본으로 제작했다. 최종 캐릭터 정체성이나 무기별 연격 수를 확정한 에셋은 아니다.

## 편집 원본과 출력

- `MannequinMotion.aseprite`: 128×128, 432프레임, 4방향(아래/위/왼쪽/오른쪽), 40태그, 9레이어.
- 기준 자세: 머리 높이 32px / 머리 포함 몸 높이 48px = 1.5등신. 발 기준 (64,104), Unity pivot (64,24), 32 PPU.
- `body`, `legs`, `hands`, `weapon`, `shadow` PNG: 부위별 432셀, 16열×27행. 손은 무기 PNG에 포함하지 않는다.
- `MannequinMotion.json`: 프레임 시간, 방향, 클립 구간, 손 좌표, 칼끝 좌표, 검 각도. 좌표는 Aseprite 좌상단 원점의 픽셀 좌표다.
- `MannequinMotion.asset`: Unity 클립/부위 Sprite 참조. 이름으로 Sprite ID를 보존해 재임포트한다.

| 동작 | 방향당 프레임 | 한 주기 | 표현 |
| --- | ---: | ---: | --- |
| idle | 8 | 640ms | 1px 호흡과 손·몸 안정 |
| walk | 12 | 560ms | 접지 → 발 회수 → 들림 → 교차 → 착지, 양발 반주기 차이 |
| dash | 6 | 160ms | 몸 숙임 → 압축 → 이동 자세 → 제동 |
| attack | 12 | 340ms | 준비 4 / 타격 4 / 회수 4, 80/120/140ms |
| attack_reverse | 12 | 340ms | 2타: 반대 궤적 베기 |
| attack_heavy | 12 | 340ms | 3타: 크게 들어 내려베기 |
| charge | 8 | 640ms | 우클릭 유지 중 두 손 수축과 몸의 압축 |
| spin | 24 | 760ms | 준비 4 / 360도 회전 16 / 회수 4, 80/480/200ms |
| hurt | 6 | 300ms | 반응 → 밀림 → 균형 회복, 자세 비교용 |
| death | 8 | 640ms | 무릎 꺾임 → 무게 이동 → 주저앉기, 자세 비교용 |

프레임 수는 저장된 프레임 수다. 미세 호흡의 일부 프레임은 같은 픽셀 자세를 유지한다. 걷기·공격은 관절 위치와 실루엣을 다시 그렸으며 래스터 팔다리 회전으로 만들지 않았다. 새로운 대검 칼날 길이는 32px이며 이전 핵심 자세의 별도 대검 원본을 수정하지 않았다.

## 훈련장

`Assets/Scenes/TrainingGround.unity`에서 Play. WASD 이동 / 마우스 조준 / 왼쪽 클릭 유지/연타 3연격 / 우클릭 유지 모으기·놓기 회전 베기 / Space 대시 / R 초기화.

- 이동 방향으로 다리, 조준 방향으로 상체를 재생한다. 공격 중 이동·대시도 같은 방식으로 합성한다.
- 준비 중 조준은 갱신하고 실행 방향은 고정한다. 연속 논리 조준/판정과 4방향 그림은 별개다.
- 실제 입력은 idle/walk/dash/attack/attack_reverse/attack_heavy/charge/spin에 연결한다. 피격·사망은 검토 전용이다. 기본 3연격은 시험용 구성이며 실제 무기 데이터의 연격 수를 확정하지 않는다.
- 피해 25, 사거리 1.45, 준비 80ms, 타격 120ms, 쿨다운 420ms, 대시 160ms 등 기존 임시 전투 값을 유지한다. 그림은 판정을 발생시키지 않는다.
- F6 검토 전환 / F7 동작 / F8 방향 / F9 일시정지 / `.` 다음 프레임 / F10 1×→0.25×→0.1×.
- 검토는 플레이어 제어와 타격을 멈춘다. 해제하면 제어를 복원하고 훈련장 시작 위치로 초기화한다. 저장 기능을 호출하지 않는다.

메뉴 `Game > Training Ground > Apply SD Mannequin`으로 현재 훈련장에 다시 적용한다. `Apply Hero V2`는 이전 아트로 복원한다. 훈련장 재생성은 새 에셋이 있으면 마네킹을 선택한다. 재생성은 기존 제작 메뉴의 씬 교체 동작이므로 수동 씬 편집을 보존한 뒤 사용한다.

## 재생성과 검증

`Tools/Art/CreateMannequinMotion.lua`를 Aseprite batch로 실행한다. 기본 출력은 이 폴더와 `Screenshots/MannequinMotion`이며 기존 원본은 기본적으로 덮어쓰지 않는다. `overwrite=true`를 지정한 재생성은 수동 편집을 잃으므로 편집 원본 보존 후에만 실행한다. 수동 수정 후에는 원본에서 내보내기를 수행한다.

확대 시트·GIF·픽셀 보고서·Unity 실행 기록은 `Screenshots/MannequinMotion`에 있다. 검증 실행 도구는 `Tools/Art/ValidateMannequinRuntime.cs`이며 Unity Pipeline `run_script`로 메모리에서 실행한다. 런타임 시험은 입력 장치를 임시 추가하고 제거하며 시간 배율·플레이어·허수아비를 복원한다.

큰 머리로 인한 뒤쪽 손/검 가림, 4방향 전환, 이동 상체와 하체의 합성은 이후 실제 플레이 감각으로 더 조정할 수 있다. 8방향·무기 교체 Prefab·다른 무기 계열·공격속도 변화·진행 저장 통합 시험은 후속이다.


## 대검 연격과 모아치기 추가 — motion-0.2

좌클릭 유지와 연타는 다음 타격 하나만 예약한다. 현재 타격 완료 뒤 우클릭 유지 요청을 우선 처리하며, 모으기 시작 전 놓으면 실행하지 않는다. 최대 1.4초 충전, 충전 중 이동 45%, 놓으면 360도 회전 베기다. 기본 타격 피해 25·사거리 1.45와 420ms 시작 간격을 유지하고 3타 회수 뒤 280ms 공백을 둔다. 특수 공격은 고정 반경 1.65, 충전 계수에 따라 피해 35→75이며 마나 20을 준비 시 예약·실행 시 차감한다. 최대 마나 100, 자연 회복 8/초다. 이 수치는 훈련장 임시 값이다.

이전 336프레임의 3,024개 셀 픽셀·위치·깊이·시간을 보존하고 회전 96프레임만 추가했다. 기존 Sprite 이름은 spriteIndex로 유지한다. 보존본은 Screenshots/MannequinMotion/BeforeComboSpin이다. 원본 확장은 CreateMannequinMotion.lua에 overwrite=true, extend_spin=true, base_root=Screenshots/MannequinMotion/BeforeComboSpin/를 지정했다. 기존 원본 대신 보존본에서 확장하는 일회성 경로이며 이후 수동 편집을 재생성으로 덮어쓰지 않는다.

RuntimeValidation.json 15개 회귀 검사와 GreatswordRuntimeValidation.json 21개 대검 검사를 통과했다. GreatswordGame.gif는 실제 입력의 전체 카메라 캡처, GreatswordGameDetail.gif는 그 영상을 캐릭터 주변으로 잘라 최근접 2배 확대한 검토용이다. 두 영상 모두 게임 시간 0.5배이며 실측 캡처 간격을 사용한다. 범위의 충전 증가·마나 최대치 변화·기절·사망 비용 해제·벽 너머 판정과 전체 저장 통합은 후속이다.
