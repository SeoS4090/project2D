# 용어 사전
## 용어

| 용어 | 문서에서의 의미 |
| --- | --- |
| 런 | 마을에서 출발해 종료 결과를 얻기까지의 한 번의 도전 |
| 덱 | 현재 런에서 사용하는 카드와 전투 능력의 집합이라는 설계안 |
| 태그 | 빌드 성향을 집계하고 조건을 판정하는 공통 분류 |
| 신성 | 빌드 조건에 따라 선택하는 고유 권능과 그 성장 체계 |
| 신화 대장간 | 장인의 양식과 현재 빌드에 따라 무기를 강화하는 시스템 |
| 만신전 | 신성 발견 기록과 영구 해금을 관리하는 시설이라는 설계안 |
| 연결 허용 시간 | 후딜 종료 후 다음 연격 입력을 기다리는 시간이며 기본 초기값은 0.2초 |
| 연격 중단 대기 | 연격을 이어 가지 않을 때 1타 재시작까지 기다리는 시간이며 종료 공백과 동일 |
| 종료 공백 | 마지막 타격을 실행한 연격의 후딜 종료 후 재공격까지의 시간 |
| 입력 예약 | 진행 중인 타격에서 다음 타격 하나의 입력을 저장하는 처리 |
