# 현재 검토할 기획 질문

전투 규칙의 기존 열린 질문은 없다. Unity 기술 선택 T01–T03을 새로 검토한다. U07–U14 여덟 질문은 2026-10-07 사용자 설계 위임에 따라 기준·데이터 의미·후속 시험을 작성하고 [[06 결정과 기록/기획 검토 완료 기록#v0.23 전투 연결 질문의 결정|완료 기록]]으로 옮겼다. U01–U06과 기존 완료 기록은 유지한다.

이는 등록된 질문의 규칙 결정 완료이며 전체 기획에 누락이 없다는 보증이나 실제 구현·밸런스 검증 완료가 아니다. 새 질문은 [[06 결정과 기록/기획 문서 상태와 검토 종료 규칙]]에 따라 새 ID로 등록한다. Excel·제작·플레이 작업은 [[06 결정과 기록/기획 진행 현황과 후속 작업]]에서 관리한다.
