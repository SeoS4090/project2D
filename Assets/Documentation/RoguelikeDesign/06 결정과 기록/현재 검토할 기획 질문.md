# 현재 검토할 기획 질문

현재 열린 질문 없음. CH12 공통 리그와 CH13 연속 조준은 실행 근거와 함께 완료 기록으로 이동했다. 남은 콘텐츠 제작·도구 이관·성능 검증은 후속 작업 목록에서 관리한다.

전투 규칙의 기존 완료 기록을 유지한다. 캐릭터 CH01–CH10과 종속 기술 T01–T03은 [[06 결정과 기록/기획 검토 완료 기록#character-1.0 캐릭터 구조와 종속 기술 질문 종료 — 2026-10-09]]에서 결정·완료 조건을 확인한다. 전체 게임의 모든 문제가 없다는 보증이나 실제 실행 검증 완료를 뜻하지 않는다.

## 캐릭터 제작 구조 — 2026-10-09

현재 기준은 [[07 Unity 기술/캐릭터 제작과 조립 구조]] character-1.3이며 공통 리그와 연속 조준 보정을 사용한다. 제작자 우선·플레이어 외형 변경 확장은 사용자 직접 결정이며 나머지 세부는 의문점 해결 위임에 따른 판단이다. 실제 아트 제작·콘텐츠 데이터·조립 도구·CV01–CV16 실행은 [[06 결정과 기록/기획 진행 현황과 후속 작업]]과 [[05 검증과 확장/프로토타입 범위와 검증]]에 남긴다.

## 새 질문 등록

실제 반례나 새 기능이 기존 계약으로 해결되지 않을 때 범위·사례·완료 조건·영향 문서와 새 ID를 등록한다. 콘텐츠 행이 비어 있거나 구현 시험을 아직 안 했다는 이유로 완료한 구조 질문을 다시 열지 않는다. 기존 답의 변경은 [[06 결정과 기록/기획 문서 상태와 검토 종료 규칙]]에 따라 개정 근거를 남긴다.
