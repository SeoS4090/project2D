# 기획 진행 현황과 후속 작업

이 문서는 기획 진행 현황을 안내한다. 기존 C·B·R·D 질문은 해당 범위에서 규칙 검토를 완료했다. 새로 발견한 질문은 별도 등록하며, 전체 설계가 빠짐없이 완료됐다는 뜻은 아니다. project2D의 훈련장·Hero V2 중간 구현과 당시 확인 기록이 있으며, 전체 게임 규칙 및 새 분리 제작안의 검증과 구분한다.

## 현재 열린 구조 질문

전투 규칙 질문은 모두 완료했고, 현재 Unity 기술 선택 T01–T03을 검토한다. U07–U14 여덟 질문은 [[06 결정과 기록/기획 검토 완료 기록#v0.23 전투 연결 질문의 결정|완료 기록]]으로 옮겼다. U01–U06 여섯 질문은 [[06 결정과 기록/기획 검토 완료 기록#v0.21 추가 전투 구조 질문의 결정|완료 기록]]으로 옮겼다. 새로운 질문은 [[06 결정과 기록/현재 검토할 기획 질문]]에 등록한다. 완료 기준과 정리 절차는 [[06 결정과 기록/기획 문서 상태와 검토 종료 규칙]]을 따른다.

## Excel 후속 작업

- [ ] 무기별 연격 타격 행, 피해·범위·사거리·준비·판정·후딜·공백·이동 배율을 작성한다.
- [ ] 장탄 수·재장전 시간·재장전 이동 배율을 작성한다.
- [ ] 마나 최대치·자연 회복·빠른 회복·행동 비용과 재사용 대기를 작성한다.
- [ ] 대시 기본·최대 증가량·거리·시간·재충전·예약 창과 피격 보호·경직·밀려남 수치를 작성한다.
- [ ] 공격속도와 대시 재충전 속도의 상·하한을 작성하고 고속 입력을 검증한다.
- [ ] 덱 용량·중복 상한·능동 지정 수·등급·태그 점수와 신성 단계 요구량을 작성한다.
- [ ] 보상 후보 수·가중치·보장 배분·가격·강화 비용·정산 비율·영구 성장 단계와 비용을 작성한다.
- [ ] 스테이지·맵·방 경로·적 패턴·예고·빈틈·동시 강공격 수를 작성한다.
- [ ] 콘텐츠 이름·지역·장인·권능·대사와 도감 행을 작성하고 기존 콘텐츠 원칙에 맞춰 검토한다.

## 제작과 플레이 검증

[[05 검증과 확장/프로토타입 범위와 검증|프로토타입 범위와 검증]]의 시나리오를 해당 구현 후 시험한다. 실제 수치·콘텐츠 다양성은 Excel 후속이다. 기존 훈련장 구현의 확인 기록이 전체 시나리오의 통과를 의미하지는 않는다. 1.5등신 마네킹의 상세 모션·훈련장 이식·3연격·충전 회전 베기의 실제 입력 시험은 [[07 Unity 기술/마네킹 모션 제작과 검증]]에 기록했다. 교체 무기 Prefab과 전체 전투·저장 통합 시험은 후속이다.

## 확장 후보

협동·복수 신성·다중 장인·실전 무기 교체·공간 인벤토리·별도 브레이크는 초기 제작 범위에 포함하지 않는다. [[05 검증과 확장/후속 확장 후보|후속 확장 후보]]에서 검토한다.

## Unity 기술 기획 시작 — tech-0.1

당시 기록: 사용자 지정으로 Unity 6.3 LTS `6000.3.18f1`와 URP 2D를 기술 기준으로 정하고 [[00 MOC/Unity 기술 MOC]]에 프레임워크·캐릭터/무기·시각효과/상태·제작 검증 초안을 작성했다. 이 시점에는 실제 Unity 구현이 없었다. 현재 기술 선택 T01–T03은 [[06 결정과 기록/현재 검토할 기획 질문]]에서 관리한다.

## 첫 Unity 제작은 훈련장 — tech-0.2

당시 기록: 사용자 결정으로 첫 제작을 훈련장 기반 전투 시험 환경으로 변경했다. [[07 Unity 기술/훈련장 기반 기술 프로토타입]]의 골격→허수아비/대검→적 대응→무기/빌드 시험 순서를 제안했다. 이 시점에는 실제 제작과 시험을 수행하지 않았다.
