## 게임데이터 규칙 정의 — data-1.0 / 2026-10-12

사용자의 게임데이터 규칙 정의 요청에 따라 [[05 검증과 확장/공개 게임데이터 사례와 적용 판단]]과 [[05 검증과 확장/게임데이터 작성과 변환 규칙]]을 작성했다. 규칙 정의와 실제 파일 이관을 구분한다.

- [x] 공개 게임 3종·엔진/도구 2종 조사, 신규 작성·ID·enum·시트·열·참조·생성·검증 규칙 정의.
- [x] 기계 스키마·int 발급/이관표·6시트 작성 구조 구현.
- [x] 35개 계보와 수치 상태·효과·카드·문서 참조 보존 이관.
- [x] 훈련소 범위의 생성 DTO·enum·typed ID·JSON·manifest와 로더/컨트롤러 연결.
- [ ] 신화 원자 효과와 기존 CommonInstant/Item/Hero·세이브 호환 이관.
- [ ] DATA-V01–V10 및 대표 무기 경로의 실제 전투 검증.

2026-10-13 현재 6시트·정수 ID 이관, 스키마/등록표/검증기/생성기, 훈련소 데이터 로딩을 구현했다. 보존 수치 179개 중 175개는 Pending이며 훈련소 임시 수치 38개를 별도 Provisional로 관리한다. Python 검사 23개, Unity 로더 검사 12개, 전투 회귀 26개가 통과했다. 신화 효과·공명·밸런스와 기존 세이브 ID 이관은 후속이다. 실제 계약과 증거는 [[05 검증과 확장/신화 빌드 Excel 데이터 계약]]를 따른다. 무기 보상·리듬 경계 등 앞선 검토 제안의 개별 채택 상태는 이번 데이터 규칙 정의로 변경하지 않는다.


## 신화 빌드 Excel 작성 — 2026-10-12

신화 빌드 Excel과 독립 검증기를 작성했다. [[05 검증과 확장/신화 빌드 Excel 데이터 계약]]에서 파일·연결 구조·검사 결과를 확인한다. 저장된 파일의 참조·계보·수치 형식·수식 오류 검사는 통과했다. 179개 수치 항목 중 175개는 미정으로 유지한다. 세부 밸런스, 원자 효과 분해, 장인·태그·공격 단계, Unity 가져오기 및 플레이 검증은 후속이다.


## 실제 신화 기반 빌드 개정 — 2026-10-11

선정 원칙은 사용자 직접 결정으로 [[게임 방향성과 콘텐츠 원칙]]에 반영했다. [[신성 테마와 무기 성장 계보]] build-0.3에서 신격·설화 기반 대표 3차 → 공통 2차 → 기본 1차 재작성을 완료했다. 기존 28종의 균등 배치는 고정 조건이 아니다. 개별 효과·아트·수치·실행 검증은 후속이다.


## Obsidian 작업 관리 구성 — 2026-10-11

문서 운영 도구를 [[개발 작업 대시보드]]와 [[Obsidian 플러그인과 작업 관리]]에 연결했다. 기존 기획 질문·게임 검증의 상태는 유지한다. 후속 구현을 시작할 때 해당 범위만 작업 명세로 구체화한다.


## 신성 테마와 무기 계보 작성 — 2026-10-11

- [x] 큰 테마와 3차·2차·1차 계보, 기본 기능/신성 공명, 카드 방향을 문서로 작성.
- [ ] 개별 신격·상징·무기 이름과 효과 후보 검토 및 콘텐츠 채택.
- [ ] 채택 범위의 장인별 지원·Weapon/Upgrade/Effect 데이터와 실제 밸런스 값 작성.

초안과 링크 확인은 문서 작업이며 게임 실행 검증이 아니다.


## 최신 캐릭터 구현 상태 — 2026-10-11

사용자 확정에 따라 이전 캐릭터 시트 코드·제작/비교 도구·프리팹 정리를 완료했다. 현행 경로·복구 위치·실행 검증은 [[07 Unity 기술/공통 리그 애니메이션 실험과 전환#현행 구현 정리 — 2026-10-11]]가 기준이다. 이하 날짜별 기록의 옛 Character Maker·시트 폴백·시험 씬 유지 안내는 당시 기록이다. 후속은 피격/기절/사망 공통 모션, 공통 리그용 제작자 카탈로그와 저장/로드 연결, 독립 빌드 및 다수 캐릭터 성능 검증이다.


이 문서는 기획 진행 현황을 안내한다. 기존 C·B·R·D 질문은 해당 범위에서 규칙 검토를 완료했다. 새로 발견한 질문은 별도 등록하며, 전체 설계가 빠짐없이 완료됐다는 뜻은 아니다. project2D의 훈련장·Hero V2 중간 구현과 당시 확인 기록이 있으며, 전체 게임 규칙 및 새 분리 제작안의 검증과 구분한다.

## 현재 열린 구조 질문

전투 규칙 질문은 모두 완료했고, 현재 등록된 열린 구조 질문은 없다. 캐릭터 관련 선택은 character-1.0 완료 기록을 따른다. U07–U14 여덟 질문은 [[06 결정과 기록/기획 검토 완료 기록#v0.23 전투 연결 질문의 결정|완료 기록]]으로 옮겼다. U01–U06 여섯 질문은 [[06 결정과 기록/기획 검토 완료 기록#v0.21 추가 전투 구조 질문의 결정|완료 기록]]으로 옮겼다. 새로운 질문은 [[06 결정과 기록/현재 검토할 기획 질문]]에 등록한다. 완료 기준과 정리 절차는 [[06 결정과 기록/기획 문서 상태와 검토 종료 규칙]]을 따른다.
