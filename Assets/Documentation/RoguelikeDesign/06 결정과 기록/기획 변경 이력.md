# 기획 변경 이력

## 캐릭터 패키지 0.1.0 생성 — 2026-10-13

사용자의 실제 생성 요청으로 [[07 Unity 기술/캐릭터 패키지 분리와 재사용]]의 구현/배포를 진행했다. 리그·공유 에셋 meta 보존 이동, Editor 제작 API 분리, 샘플 GUID 분리, 자동 빌드의 특정 외형 의존 제거와 tgz/ZIP을 완료했다. 독립 설치/빌드·제작 재현 검사는 통과했고 기존 프로젝트 실행 회귀는 점유 Editor 연결 문제로 미실시다. 기획의 미구현 커스터마이징·저장 기능을 패키지 기능으로 승격하지 않았다.

## 캐릭터 재사용 패키지 구성 조사 — 2026-10-13

사용자의 다른 프로젝트 재사용 조사 요청에 따라 [[07 Unity 기술/캐릭터 패키지 분리와 재사용]]를 작성하고 Unity 기술 MOC·진행 현황·인계에 연결했다. 핵심 리그와 프로젝트 전투/생성 설치 코드의 경계를 확인하고 UPM 및 제작 ZIP을 추천했다. 기존 기획 계약과 코드·에셋·씬은 변경하지 않았으며 패키지 제작 및 독립 실행 검증은 후속이다.

## 게임데이터 작성·변환 규칙 정의 — data-1.0 / 2026-10-12

사용자 요구와 조사 위임으로 [[05 검증과 확장/공개 게임데이터 사례와 적용 판단]] 및 [[05 검증과 확장/게임데이터 작성과 변환 규칙]]을 작성했다. 신규 계약에서는 문자열 콘텐츠 ID와 논리 표당 시트 제안을 int·enum·6개 작업 시트·이름 있는 표·생성 C#/JSON으로 대체한다. 변경 이유는 재사용과 작성 동선 개선이며 의미·참조·미정 수치 보존을 우선한다.

열 정의·Excel 연결·관계 절차·게임데이터 MOC·현행 data-0.1 계약의 구분·인계·후속 작업·검증 계획을 연결했다. 실제 Excel·기계 스키마·검사기·런타임 코드는 이관하지 않았다. 기존 전투·성장 규칙과 개별 무기 콘텐츠 채택은 유지한다. 새 DATA-V01–V10은 미실시다.


## 신화 빌드 Excel 작성 — 2026-10-12

신화 빌드 Excel과 독립 검증기를 작성했다. [[05 검증과 확장/신화 빌드 Excel 데이터 계약]]에서 파일·연결 구조·검사 결과를 확인한다. 저장된 파일의 참조·계보·수치 형식·수식 오류 검사는 통과했다. 179개 수치 항목 중 175개는 미정으로 유지한다. 세부 밸런스, 원자 효과 분해, 장인·태그·공격 단계, Unity 가져오기 및 플레이 검증은 후속이다.


## 실제 신격 기반 무기 계보 전면 재작성 — build-0.3 / 2026-10-11

사용자의 재작성 요청에 따라 [[신성 테마와 무기 성장 계보]]의 이전 상세 표를 교체했다. 제우스·토르·아폴론·아레스·하데스·아르테미스·스카디의 설화에서 18개 3차를 설계하고 공통 행동으로 10개 2차·7개 1차에 연결했다. 전승/각색·신성 없는 기본 기능·실패/보스 처리·카드/아트·데이터·BUILD-V01–V11을 기록했다. 과거 28종 균등 배치와 태양 가칭을 현행 원본에서 제거했다. 개별 효과는 설계 제안이며 구현·플레이 검증은 미실시다.


## 신화 신격 선정 범위 명확화 — 2026-10-11

사용자는 대중 판타지·소설·게임·영화·애니메이션에서 흔히 사용하는 신격은 허용하고 현재 널리 이어지는 종교의 신격은 제외하도록 직접 결정했다. [[게임 방향성과 콘텐츠 원칙]]과 R04·인계에 반영하고 [[신성 테마와 무기 성장 계보]] build-0.2에 실제 신격 후보·설화 출처·게임적 각색·계보 재설계 방향을 기록했다. 개별 효과 채택이나 구현·밸런스 검증 완료를 뜻하지 않는다.


## Obsidian 작업 관리 구성 — 2026-10-11

사용자의 공유 채팅 검토 및 Obsidian 관리 요청에 따라 Templater·Dataview를 도입하고 작업 명세/시스템/결정/결과 템플릿과 [[개발 작업 대시보드]]를 추가했다. 기존 `status`와 작업 진행 속성을 분리하고 [[Obsidian 플러그인과 작업 관리]]에 설치·보류·복구 기준을 기록했다. 게임 규칙 변경은 없다.


## 신성 테마와 무기 성장 계보 — 2026-10-11

사용자가 세계관에 맞는 빌드 기획을 신들의 큰 테마 → 3차 무기 → 공통 테마의 2차 무기 → 1차 무기 순서로 요청했다. [[03 빌드와 무기/신성 테마와 무기 성장 계보]] build-0.1에 콘텐츠 초안을 작성하고 빌드 MOC·인계·진행 목록·검증 계획을 연결했다.

기존 B04의 기본 무기→신화 양식→기능 강화와 B05의 신성 성장 구분을 유지했다. 3차 무기는 기존 종류를 유지하며 기본 기능과 조건부 공명을 구분하는 제안이다. 개별 신격 이름의 사용 판정·콘텐츠 채택·Excel 수치·플레이 검증은 후속이다.

초기에는 Obsidian 미실행/CLI 비활성 상태를 확인했고, 사용자가 실행 및 CLI 활성화를 완료한 뒤 `vault=project2D`를 지정하여 Obsidian API로 작성했다. 일반 파일 편집은 임시 초안에만 사용했으며 개인 Vault와 보존 원본은 수정하지 않았다.


## 이전 캐릭터 구현 정리 — 2026-10-11

사용자의 조작·렌더링 확정 및 이전 코드/프리팹 정리 요청을 반영했다. 공통 리그 전용 뷰·검토, Azure 직접 프리팹, SharedRig 경로와 생성기 정리를 완료하고 옛 시트/조립/시험 구현을 복구 가능한 외부 보관본으로 분리했다. 전투 규칙 변경은 없다. 검증 근거와 남은 구현은 [[07 Unity 기술/공통 리그 애니메이션 실험과 전환#현행 구현 정리 — 2026-10-11]]에 기록했다.


## v0.18 현재 적용 기준

2026년 10월 7일: 사용자 요청에 따라 2D 핵앤슬래시 인접 사례 다섯 작품의 공식 자료를 조사하고 미검토 구조 항목을 보강했다. v0.18의 새 기준은 해결 위임에 따른 설계 판단이며 과거 사용자 개별 발언과 구분한다. 기존 대시·연격·피격 규칙을 유지했다. 수치와 콘텐츠 다양성의 Excel 후속 경계를 유지하고 이전 상충 초안은 보관 기록으로 이동했다. [[기획 검토 완료 기록|범위와 변경 추적]] · [[05 검증과 확장/2D 핵앤슬래시 장르 조사|출처]].

## 통합 기획서 0.1

세계관, 핵심 루프, 훈련장, 만신전과 영구 성장, 카드와 무기, 신성 및 신화 대장간을 한 문서로 정리했다.

## 통합 기획서 0.2

브레인스토밍 답변 모음을 반영해 맵 기믹, 훈련장 측정, 영구 성장 분류, 덱 대안, 빌드 예시와 확장 후보를 보강했다.

## 통합 기획서 0.3

기본 전투 장을 추가해 탑다운 시점, 스태미나와 점프 제외, 마나 회복, 무기별 연격, 입력 예약, 타격 취소, 연결 허용 시간, 중단 대기와 공격속도 적용을 반영했다. 관련 요약, 미정 목록, 훈련장 시험 기준과 확장 데이터 항목도 함께 갱신했다.

훈련장의 초기 영구 성장 역할은 이후 정의에 맞춰 시험 기능으로 정리한다. 광범위한 신화권 사용 후보에는 현존 숭배 신격 제외 원칙을 우선 적용한다. 카드 수에 따른 자동 숙련도와 별도 대장간 변형은 대안으로 구분한다. 손패, 슬롯 수, 보조 신성과 구체적 수치는 사용자 결정과 검증 전까지 설계안 또는 미정으로 유지한다.

이번 전투 규칙에서는 버튼 해제 즉시 연격을 초기화하는 방식을 누르고 있기와 연타를 모두 지원하는 연결 방식으로 변경했다. 공격속도는 일부 공백에 다른 비율을 적용하지 않고 전체 사이클에 동일하게 적용한다. 무기별 횟수와 대검의 1.5초 및 0.5초는 계산 예시로 유지하고, 연결 허용 시간 0.2초는 조정 가능한 초기값으로 구분한다.

## Obsidian 문서화

2026년 10월 7일에 신규 vault를 만들고 0.3 버전 내용을 주제별 문서와 MOC로 분리했다. 규칙의 확정 상태는 유지하며, 문서 구조와 내부 연결을 추가했다. 이후 작업 문서는 vault에서 관리하고 원본은 참고자료로 보존한다.

## 앞으로 기록할 내용

변경일, 변경한 규칙, 변경 이유, 영향을 받는 문서와 검증 결과를 남긴다. 초안 채택과 수치 조정 및 규칙 철회를 구분한다.

## Excel 관리 방향과 열 연결 0.5 초안

## 조준과 이동 규칙 확정 0.6

2026년 10월 7일 사용자 동의에 따라 이동과 조준의 분리, 준비 중 방향 변경 및 실행 순간 타격별 방향 고정, 모든 기본 공격 구간의 이동 허용과 무기별 감속, 공백 중 정상 이동 및 근접 판정과 투사체의 위치 처리 규칙을 채택했다. 실제 감속 값은 Excel에서 추후 작성한다. 패드와 조준 보조 및 회피 처리는 미정으로 유지한다. 주제 문서와 전투 원칙, 확정 기록 및 검토 목록과 시험 기준을 갱신했다. 구현 및 플레이 시험은 아직 진행하지 않았다.

## 대시 충전 구조 확정 0.7

2026년 10월 7일 사용자 결정에 따라 대시를 충전 횟수와 재충전 시간으로 제한한다. 기본 최대 횟수는 게임데이터에서 지정하고 빌드로 증가하며, 사용 시 차감하고 쿨타임 후 회복한다. 기존 단일 재사용 대기 제한과 추가 충전을 확장 후보로만 두던 제안은 이 구조로 대체했다. 순차 및 독립 충전 또는 전체 회복의 선택, 실제 수치와 공격 중 회피 처리는 미정이다.

## 대시 순차 충전 확정 0.8

2026년 10월 7일 사용자 동의로 실제 실행 시 충전 1개 소비, 하나의 타이머로 쿨타임마다 순차 회복, 추가 사용 시 타이머 유지, 최대 충전 도달 시 충전 종료 및 남은 충전으로 회복 중 사용 가능을 채택했다. 관련 미정 작업을 완료 표시하고 게임데이터 recharge_sec의 의미와 시험 기준을 갱신했다. 실제 수치와 최대 횟수 변경 시 처리, 회복 속도 능력치 및 회피 조작은 미정이다. 구현이나 플레이 시험 결과는 포함하지 않는다.

## 연속 대시 방향 확정 0.9

2026년 10월 7일 사용자 결정으로 각 대시에서 다른 방향을 선택할 수 있도록 확정했다. 왼쪽 대시 후 오른쪽 대시를 예시로 기록하고 이전 방향이 다음 대시를 제한하지 않는 규칙을 추가했다. 기존 대시 중 추가 예약을 허용하지 않는 초안은 미정 항목으로 구분해 다음 검토에 남긴다. 방향의 입력 기준과 결정 시점 및 한 대시 중 방향 변경 여부는 아직 채택하지 않았다.
