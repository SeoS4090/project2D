# 기획 변경 이력

## v0.18 현재 적용 기준

2026년 10월 7일: 사용자 요청에 따라 2D 핵앤슬래시 인접 사례 다섯 작품의 공식 자료를 조사하고 미검토 구조 항목을 보강했다. v0.18의 새 기준은 해결 위임에 따른 설계 판단이며 과거 사용자 개별 발언과 구분한다. 기존 대시·연격·피격 규칙을 유지했다. 수치와 콘텐츠 다양성의 Excel 후속 경계를 유지하고 이전 상충 초안은 보관 기록으로 이동했다. [[기획 검토 완료 기록|범위와 변경 추적]] · [[05 검증과 확장/2D 핵앤슬래시 장르 조사|출처]].

## 통합 기획서 0.1

세계관, 핵심 루프, 훈련장, 만신전과 영구 성장, 카드와 무기, 신성 및 신화 대장간을 한 문서로 정리했다.

## 통합 기획서 0.2

브레인스토밍 답변 모음을 반영해 맵 기믹, 훈련장 측정, 영구 성장 분류, 덱 대안, 빌드 예시와 확장 후보를 보강했다.

## 통합 기획서 0.3

기본 전투 장을 추가해 탑다운 시점, 스태미나와 점프 제외, 마나 회복, 무기별 연격, 입력 예약, 타격 취소, 연결 허용 시간, 중단 대기와 공격속도 적용을 반영했다. 관련 요약, 미정 목록, 훈련장 시험 기준과 확장 데이터 항목도 함께 갱신했다.

훈련장의 초기 영구 성장 역할은 이후 정의에 맞춰 시험 기능으로 정리한다. 광범위한 신화권 사용 후보에는 현존 숭배 신격 제외 원칙을 우선 적용한다. 카드 수에 따른 자동 숙련도와 별도 대장간 변형은 대안으로 구분한다. 손패, 슬롯 수, 보조 신성과 구체적 수치는 사용자 결정과 검증 전까지 설계안 또는 미정으로 유지한다.

이번 전투 규칙에서는 버튼 해제 즉시 연격을 초기화하는 방식을 누르고 있기와 연타를 모두 지원하는 연결 방식으로 변경했다. 공격속도는 일부 공백에 다른 비율을 적용하지 않고 전체 사이클에 동일하게 적용한다. 무기별 횟수와 대검의 1.5초 및 0.5초는 계산 예시로 유지하고, 연결 허용 시간 0.2초는 조정 가능한 초기값으로 구분한다.

## Obsidian 문서화

2026년 10월 7일에 신규 vault를 만들고 0.3 버전 내용을 주제별 문서와 MOC로 분리했다. 규칙의 확정 상태는 유지하며, 문서 구조와 내부 연결을 추가했다. 이후 작업 문서는 vault에서 관리하고 원본은 참고자료로 보존한다.

## 앞으로 기록할 내용

변경일, 변경한 규칙, 변경 이유, 영향을 받는 문서와 검증 결과를 남긴다. 초안 채택과 수치 조정 및 규칙 철회를 구분한다.

## Excel 관리 방향과 열 연결 0.5 초안

2026년 10월 7일 사용자 결정에 따라 수치와 콘텐츠 다양성을 추후 게임데이터 Excel에서 관리하는 방향을 반영했다. 기획 문서에는 동작 규칙과 열의 의미 및 ID 연결을 남긴다. 게임데이터 MOC와 관리 원칙, 열 정의 및 추가 절차를 작성했다. 실제 Excel과 수치 행 및 자동 변환 기능은 아직 작성하지 않았다. 기존 숫자 제안은 설명용 기록으로 구분하고 확정 규칙은 유지했다.

## 대시 충전 구조 확정 0.7

## 대시 순차 충전 확정 0.8

## 연속 대시 방향 확정 0.9

2026년 10월 7일 사용자 결정으로 각 대시에서 다른 방향을 선택할 수 있도록 확정했다. 왼쪽 대시 후 오른쪽 대시를 예시로 기록하고 이전 방향이 다음 대시를 제한하지 않는 규칙을 추가했다. 기존 대시 중 추가 예약을 허용하지 않는 초안은 미정 항목으로 구분해 다음 검토에 남긴다. 방향의 입력 기준과 결정 시점 및 한 대시 중 방향 변경 여부는 아직 채택하지 않았다.

## 대시와 기본 공격 독립 실행 확정 0.10

## v0.21 추가 전투 구조 설계

사용자 설계 위임에 따라 PoE·Last Epoch·LoL·Warframe 공식 사례를 조사하고 U01–U06의 규칙을 정했다. 피해 축과 성분, 능력치 합산, 면역 획득, 적 행동·시야·경로, 전방 판정, 타격 연출 시간을 보강했다. 기존 모호한 D10·D12·C12 설명을 새 기준에 연결하고 데이터 필드와 18개 후속 검증 시나리오를 추가했다. 열린 질문 여섯 개를 완료 기록으로 옮겼다. 실제 숫자·콘텐츠·게임 구현·플레이 검증은 후속이다.

## v0.23 전투 연결 질문 전체 보강

U07–U14를 전부 기획하도록 위임받아 현재 기준을 추가했다. 동시 사건은 방어값을 묶음별 고정하고 피해·사망·상태·회복·후속 발동으로 처리한다. 패링 보상과 적 반응을 구분하며, 기절 중 방어 종료·타격 전체 대상 상한·비용 준비 시 고정·root 수명·예고 후 조건 상실·방 전환 및 논리적 쿨타임 그룹을 명시했다. 기존 C·D·U·B·R 주제 문서와 데이터 정의를 연결하고 24개 미실시 시험을 작성했다. 완료 조건을 보존해 활성 목록에서 완료 기록으로 옮겼다. 실제 수치·콘텐츠·구현·플레이 검증은 후속이다.

## 2026-10-07 반복 기획 작업의 스킬화

세션의 반복 작업을 두 프로젝트 스킬로 만들었다. `roguelike-design-review`는 구조 질문·결정 반영·데이터 연결·검토 종료를, `obsidian-design-audit`는 읽기 전용 연결·상태 검사를 담당한다. 스킬과 검사 도구의 형식·참조·실제 오류 검출을 확인하고 사용 안내를 운영 MOC에 연결했다. 기존 45개 과거 상태 표기는 보고만 했고 기획 규칙·수치·실제 게임 검증 상태와 보존 원본은 변경하지 않았다.

## 2026-10-07 Unity 프레임워크 기술 초안

## 2026-10-08 캐릭터 비율과 별도 무기 제작 문서화

사용자가 인체 비율·32×64 고정 전제를 재검토하고 캐릭터와 무기를 따로 생성하여 별도 Prefab으로 장착하는 방식을 제안했다. 이어 해당 내용을 Vault로 정리하고 Git에 올리도록 요청했다. 비율·픽셀 제작과 분리 생성·장착을 두 주제로 정리하고, 기존 표현 기획·Unity 목차·활성 질문·제작 순서·현황·인계를 연결했다. 기존 project2D 훈련장·Hero V2 기록과 새로운 미구현 제작안을 구분했다.

기존 약 3등신·32/40px 비교 제안과 4방향+연속 회전 추천을 고정 조건으로 취급하지 않는다. 방향 수·회전 방식·양손 포즈·합성 범위·규격은 T01·T03에 남겼다. 최종 아트·전투 수치·코드 적용·새 구조의 플레이 검증은 이번 문서화로 완료 처리하지 않았다. 게임 규칙 v0.23과 보존 참고자료는 유지한다.

작성 환경에서 Obsidian CLI 명령과 실행 중인 Obsidian 인스턴스가 확인되지 않아 일반 파일 도구로 편집했다. 대상은 project2D에 포함된 `RoguelikeDesign` Vault이며, 개인 Vault와 원본 `roguelike-design` 저장소에 자동 동기화된 것으로 취급하지 않는다. 연결·속성은 변경 노트에 대한 문서 점검으로 확인하고, Obsidian 읽기 화면 확인은 미실시로 구분한다.

문서 점검 결과: 변경 노트와 README 10개에서 오류 0건, 경고 2건. 경고는 기존 README의 frontmatter·status가 없는 형식에 대한 안내다. 이 결과는 문서 연결·속성 검사이며 새 아트나 게임 실행의 검증 결과가 아니다.
