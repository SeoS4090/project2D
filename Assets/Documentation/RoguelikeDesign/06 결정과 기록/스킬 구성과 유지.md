# 스킬 구성과 유지

## 현재 포함한 스킬

| 스킬 | 저장 위치 | 사용하는 작업 |
| --- | --- | --- |
| obsidian-cli | `.agents/skills/obsidian-cli/SKILL.md` | 실행 중인 Obsidian의 노트 작성·검색·속성·이동과 연결 확인 |
| obsidian-markdown | `.agents/skills/obsidian-markdown/SKILL.md` | wikilink·속성·콜아웃 등 Obsidian 문법과 읽기 화면 확인 |

2026-10-07 이 컴퓨터에 설치돼 있던 두 스킬의 파일과 Markdown 참조 파일을 그대로 복사했다. 프로젝트 전용 동작 원칙은 루트 `AGENTS.md`와 운영 문서에서 관리하고 복사한 스킬 본문은 수정하지 않았다. 파일 목록·출처 표시·SHA-256은 `.agents/skills-manifest.json`에 기록한다. 이후에도 같은 파일인지 확인할 수 있도록 Git이 스킬 사본의 줄바꿈을 자동 변환하지 않게 설정했다.

숨김 폴더의 스킬은 Obsidian 일반 노트 목록에 나타나지 않을 수 있다. 이 문서가 Vault의 안내 역할을 맡는다. Codex 또는 파일 탐색기에서 위 위치를 열어 확인한다.

## 다른 컴퓨터에서 사용

저장소 전체를 내려받고 그 안에서 Codex를 시작한다. 저장소 스킬 경로는 `.agents/skills/`이다. 전역 설치를 추가하지 않아도 프로젝트용 사본을 제공하는 구조다. 동일 이름의 전역 스킬이 있으면 목록에 둘 다 나타날 수 있으므로 프로젝트 경로를 명시해 읽는다. 인식되지 않으면 새 세션을 열어 확인한다. [공식 스킬 탐색 안내](https://learn.chatgpt.com/docs/build-skills)

CLI 스킬은 Obsidian 앱과 CLI가 필요하다. 도움말로 사용 가능한 명령을 확인하고 Vault 이름을 첫 인수로 지정한다. Markdown 스킬의 `references/`는 상대 경로를 유지한다. 숨김 폴더는 읽기 전용 ChatGPT 미러의 스킬 설치 위치가 아니며 실제 Git 저장소의 스킬 위치다.

## 추가 스킬의 기준

- 실제 Excel 작성·편집을 시작할 때 그 환경의 스프레드시트 스킬과 런타임을 확인한다. 현재는 Excel 작성 이전이므로 해당 플러그인·런타임을 저장소에 복제하지 않았다.
- Canvas·Bases 파일을 실제로 만들 때 필요한 스킬을 추가한다. 일반 MOC 작성에는 두 기본 스킬을 사용한다.
- Unity 구현을 시작하면 게임 소스 저장소에서 사용 엔진과 연결 방식에 맞는 Unity 스킬을 구성한다. 현재 기획 Vault를 게임 구현 프로젝트로 취급하지 않는다.
- 스킬 추가 시 실제 과업, 출처, 의존 앱·연결·런타임, 참조 파일, 사용 확인 결과를 기록한다. 로그인이나 인증 정보는 포함하지 않는다.

## 갱신 절차

현재 사본과 새 스킬의 지침·참조 파일 차이를 확인한 뒤 함께 갱신하고 manifest의 날짜와 해시를 다시 계산한다. 스킬 복사·참조 파일 확인과 실제 도구 동작 확인은 구분한다. 다른 컴퓨터의 CLI 실행·Codex 자동 인식은 그 컴퓨터에서 확인할 후속 항목이다.
