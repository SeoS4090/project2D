# 기획 검토 완료 기록

범위는 이전 미정 목록의 모든 미완료 작업, 우선 분야 일곱 가지, 열세 상세 검토안과 현재 주제 문서에 남은 구조 질문이다. 구조를 해결한 작업과 실제 수치·콘텐츠·플레이 검증을 구분한다. 기존 사용자 확정 사항을 바꾸지 않고 이번 위임 범위에서 새 설계 기준을 정했다.

이 문서는 과거 질문의 해결 기록이다. 현재 열린 질문은 [[06 결정과 기록/현재 검토할 기획 질문]]에서 확인한다.

## 해결 여부를 확인한 기준

- 모든 이전 미완료 항목에 적용 규칙이나 명시적인 Excel 후속 경계가 있다.
- 입력·피격·특수행동·자원·덱·태그·대장간·신성·보상·성장·저장·훈련·반복 서사의 질문을 각각 다뤘다.
- 장르 자료로 확인한 사실과 우리 게임의 판단을 분리했다. 근거가 없는 세부 프레임을 타 게임 공통 규칙으로 표기하지 않았다.
- 이전의 기술 준비 취소·대시 우선 예약 삭제·활 매 발사 재장전·별도 재장전속도·교체 후 비활성 전용 카드 방치 제안은 현재 기준으로 대체했다.
- 원래 수치 예시는 보관만 하며 실제 값으로 자동 채택하지 않는다.
- 이 목록은 문서 범위 감사이며 구현 및 실제 플레이 시험의 결과가 아니다.

## CH12 공통 리그 애니메이션 재사용 검증 — rig-lab-0.1

사용자의 SPUM 방식 재확인과 후속 “진행하자” 요청에 따라 같은 피벗 리그에서 푸른 튜닉/청동 갑옷과 서로 다른 대검 그림을 공통 클립으로 재생했다. 완료 조건인 걷기·베기, 4방향·반대 이동, 양손 연결, 픽셀 표시 비교를 수행했다. 15개 샘플/렌더 검사와 실제 Play 입력 10개를 통과했고 24,768회 샘플에서 최대 그립 오차는 0.031571px, 두 외형의 관절 자세 차이는 0이었다.

기본 제작 방식은 공통 Transform 클립과 리그로 정하고, 방향/특수 실루엣만 그림을 보완한다. 기존 실시간 회전 일괄 금지/16각 그림 선행 강제는 이 기본 방식에 맞춰 개정했다. 사용자 직접 의도는 공통 모션 재사용이며 구체적인 Playables/마스크·그림 경계는 실행 결과에 따른 설계 판단이다.

근거: [[07 Unity 기술/공통 리그 애니메이션 실험과 전환]]. 기준: [[07 Unity 기술/캐릭터 제작과 조립 구조#체형·모션과 제작 방식 — CH03 및 T01]]. 이는 전투 전체 이관/완성 아트/연속 조준 검증 완료가 아니다. 실제 연속 조준 요구는 새 CH13으로 등록했다.

## CH13 연속 조준과 양손 리그 연결 — 2026-10-10

계기는 CH12의 4방향 시험만으로 기존 연속 마우스 조준을 표현할 수 없다는 점이었다. 원래 완료 조건은 방향 경계와 연속 각도에서 걷기/대검 공격의 손·소매 연결/가림을 확인하고 곡선·리그 보정·별도 그림의 제작 책임을 정하는 것이다.

후속 작업 요청과 설계 위임에 따라 기준 방향 공통 클립의 무기 궤적을 조준으로 회전하고 고정 길이 팔을 보정하기로 결정했다. 준비 추적·실행 방향 고정·독립 하체·외형 간 모션 공유와 원본 1px 연결 기준을 유지한다. rig-lab-0.1의 에디터 계산만 사용하던 범위에서 런타임 팔 보정을 추가했으며 새 체형/그립의 무조건 호환을 허용하지 않는다.

103,320 자세에서 양손 최대 오차 0.00000853px, 도달 범위 보정 0px, 방향 경계 궤적 연속성을 확인했다. 8방향 그림과 실제 훈련장 화면, 고정 소매 부착점/무기 앞뒤 순서를 확인했다. 검사 20개·어댑터/UI 9개·실제 전투 24개 통과. 모션 제작자는 궤적/구간, 리그는 관절/그립/연속 보정, 아트 제작자는 정적 방향 그림/특수 실루엣을 소유한다.

기준: [[07 Unity 기술/캐릭터 제작과 조립 구조#연속 조준과 양손 연결 — CH13]]. 근거와 미실시 범위: [[07 Unity 기술/공통 리그 애니메이션 실험과 전환#연속 조준과 훈련장 적용 — rig-lab-0.2]]. 최종 아트·모든 체형·상태 모션·출하/성능 검증 완료를 뜻하지 않는다.
