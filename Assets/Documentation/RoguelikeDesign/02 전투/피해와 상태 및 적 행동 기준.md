# 피해와 상태 및 적 행동 기준

## 적용 범위

U01–U06 추가 구조 질문의 현재 설계 기준이다. 기존 C·B·R·D 규칙을 유지하며 모호했던 분류와 조건을 보강한다. 사용자의 설계 위임에 따른 결정이며 개별 사용자 확정과 구분한다. 실제 숫자·무기·적·속성 종류는 Excel 후속 작업이고 구현·플레이 검증은 미실시다. 근거와 적용 판단: [[05 검증과 확장/RPG와 액션 게임 전투 규칙 비교]].

## U01 피해 성질과 적용 방식

연결 상황의 상세 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U07 동시 피해와 발동 효과의 순서|U07]].

피해를 `damage_type`(물리 또는 데이터로 정의한 속성 ID), `delivery_kind`(direct 또는 periodic), `source_kind`(기본 공격·특수행동·능동 기술·추가 효과)로 구분한다. 근접·투사체·폭발은 공간 판정 방식이다. 직접 피해에 물리와 속성이 있을 수 있고 지속 피해에도 물리와 속성이 있을 수 있다. 이 분류 자체로 독·출혈 등 실제 콘텐츠를 채택하지 않는다.

물리 직접·물리 지속 피해 모두 방어 감소율 `방어력/(방어력+양수 기준 상수)`를 적용한다. 속성 직접·속성 지속 피해 모두 해당 속성 저항만 적용하며 물리 방어력을 중복 적용하지 않는다. 저항은 감소 비율이고 최종 허용 범위는 `0 이상, 1 미만` 안에서 데이터로 제한한다. 약점은 음수 저항 대신 받는 피해 증가로 표현한다. 초기 범위에는 고정 피해·방어 관통·피해 전환을 넣지 않는다. 피해 무적과 상태 면역은 감소율과 별개다.

한 타격에 여러 피해 성질을 넣으면 DamageComponent별로 계산한 뒤 같은 적중 사건의 합계로 HP에 한 번 적용한다. C05의 동시 직접 피해 후보 비교는 성분 합계로 한다. 동일 타격·대상의 치명타 추첨은 한 번이며 can_crit인 직접 성분에만 같은 결과를 사용한다. 성분 수 때문에 피격 보호·경직·적중 보상을 여러 번 발생시키지 않는다. 최종 실제 HP 감소량으로 흡혈을 계산한다.

지속 피해는 별도 계수와 공격자 실행 스냅샷으로 계산하고, 유발한 직접 타격의 방어 후 피해나 치명타 피해를 다시 기본값으로 사용하지 않는다. 기본 지속 피해는 치명타·직접 적중 효과·피격 보호·경직·밀려남을 발생시키지 않는다. 매 틱 대상의 현재 방어·저항·받는 피해 보정을 읽는다. 대시 중 틱 차단과 시간 진행은 C08을 유지한다.

## U02 강화·약화 효과의 합산

일반 능력치는 `현재 기본값 + 고정량 합계`를 구한 뒤 `1 + 증가 비율 합계 - 감소 비율 합계`를 곱하고 최종 능력치 허용 범위로 제한한다. 같은 능력치·같은 단계의 보정만 합산한다. 음수 중간값으로 피해나 회복의 의미를 뒤집지 않도록 비율 계수는 최소 0으로 제한한다. 공격자 피해 증가와 대상 받는 피해 증가는 별도 단계다. 각 단계 내부는 부호 있는 비율 합산, 단계 사이는 순서대로 곱한다. 별도 최종 배율 효과는 명시적인 final_multiplier만 허용하고 일반 증가 효과를 임의 곱셈으로 취급하지 않는다.

이동속도 감속 상태는 여러 출처를 유지하되 현재 살아 있는 가장 강한 감속 하나만 적용한다. 일반 이동 능력치 계산 뒤 `1-가장 강한 감속 비율`, 행동 이동 배율을 순서대로 곱한다. 강한 감속이 끝나면 아직 남은 약한 감속이 적용된다. 가속은 일반 이동 능력치의 증가 보정이다. 대시 경로는 이동속도·감속·행동 감속의 영향을 받지 않는다. 감속은 기절이 아니며 이를 통해 이동속도가 0이 되지 않게 데이터 하한을 둔다.

공격속도는 C16의 증가량 합산과 cycle 스냅샷 규칙만 사용한다. 대시 재충전 속도도 C03의 별도 합산 규칙을 유지한다. 범용 능력치 연산으로 이 두 규칙을 덮어쓰지 않는다. 최대 대시 횟수는 정수 고정량 합산만 지원한다. 치명타 확률·저항처럼 비율 자체가 능력치인 값은 퍼센트포인트 가감으로 합산하고 허용 범위로 제한하며 초기 범위에서 비율의 비율 증가는 지원하지 않는다.

동일 상태·동일 효과 출처의 갱신과 다른 출처의 상태 상한은 D12를 유지한다. 보정 합산은 살아 있는 인스턴스 집합에서 다시 계산하여 적용 순서에 따라 값이 달라지거나 만료 시 잘못 차감되지 않게 한다. ability_stat 분류의 강화와 약화는 별도 stack_group으로 관리하고 상태 상한에서 양수 강화와 음수 약화를 절대값만으로 경쟁시키지 않는다. 감속끼리의 선택과 상태 저장 상한은 서로 다른 처리다.

## U03 해제·상태 면역·피해 무적

연결 상황의 상세 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U09 기절 중 방어 종료|U09]].

해제는 지정한 해로운 상태를 즉시 제거하는 일회 효과다. 상태 면역은 지정한 상태 ID 또는 분류의 새 부착을 막는 동안 유지되는 효과다. 초기 공통 규칙에서 상태 면역을 얻으면 해당 범위의 기존 해로운 상태도 제거한다. 강화 상태에는 이 제거 규칙을 적용하지 않는다. 단순히 피해 저항을 얻거나 대시를 시작하는 것은 상태 면역 획득이 아니다. 대시는 기존 지속 상태를 제거하지 않고 해당 틱 피해만 차단한다.

면역 중 부착 요청은 실패하고 저장하지 않는다. 면역 종료 뒤 이전 상태를 부활시키거나 막았던 피해를 몰아주지 않으며 새로운 유효한 부착만 적용한다. 같은 면역의 다른 출처는 각각 유지하고 마지막 출처가 종료돼야 면역이 끝난다. 지속적인 상태 영역은 다음 정상 부착 시점에 다시 검사하며 면역 종료만으로 즉시 추가 틱을 만들지 않는다.

상태 지속시간 감소는 면역이 아니다. 부착·재부착 시 현재 기간 보정으로 새 종료 시각을 계산하고 D12의 늦은 종료 시각 갱신 규칙을 적용한다. 이미 적용된 상태의 남은 기간을 능력치 변화만으로 재계산하지 않는다. 기간 감소의 상한은 1 미만이고 완전 차단은 명시적 면역으로 표현한다.

기절 해제로 행동 제한이 풀려도 기절 때문에 취소된 준비·삭제된 예약·소비된 비용은 복구하지 않는다. 이미 실행한 타격의 후딜·재공격 대기 등 기존 시간은 유지한다. 강공격 단계의 약한 경직 면역은 해당 경직에만 적용하고 지속 피해·기절·밀려남에 자동 확장하지 않는다. 같은 시각 면역 시작은 D04의 행동 시작/방어 상태 갱신 단계에서 적용한 후 부착을 검사한다.

## U04 적의 공통 행동과 경로

연결 상황의 상세 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U13 예고 후 조건 상실|U13]].

적은 출현→접근/재배치→준비→실행→후딜을 기본 흐름으로 사용한다. 행동 선택 우선순위는 사망·방 종료, 출현과 기절/경직 처리, 이미 시작한 동작 마무리, 표적 확인과 경로 재배치, 실행 가능한 공격 선택, 대기다. 새 판단만으로 준비 중인 공격을 다른 기술로 교체하지 않는다. 경직·패링에 의한 취소는 기존 명시 규칙을 따른다.

초기 단일 플레이에서는 살아 있는 현재 방 플레이어 한 명만 표적이다. 방 전투 시작으로 적을 활성화하되 시야가 없으면 벽 너머의 최신 위치를 공격에 사용하지 않는다. 직접 시야로 본 마지막 위치를 기억해 접근하고, 시야를 잃으면 기억 유지 시간 동안 마지막 위치까지 경로를 찾은 후 지정 탐색 지점으로 재배치한다. 재탐색은 정해진 주기와 큰 경로 변경 시 수행하며 공격 입력을 읽어 즉시 반응하는 방식은 쓰지 않는다.

근접 적은 공격 시작 거리 안에 들어오고 직접 경로가 열렸을 때 후보를 고른다. 원거리 적은 최소 거리와 최대 거리 사이를 유지하며 너무 가까우면 후퇴, 너무 멀거나 사선이 막히면 접근·옆 이동한다. 선호 거리는 그 구간 안에 둔다. 접근 진입 거리와 접근 종료 거리를 구분하여 경계에서 매 순간 앞뒤로 떨지 않게 한다. 준비 중 추적 조준과 실행 시 방향 고정은 C10을 따른다. 준비 중 벽 뒤로 피한 플레이어를 추적해 벽을 무시한 판정을 만들지 않는다.

벽과 고정 장애물을 우회하고 적끼리 겹침을 완화한다. 막힌 경로는 재계산하고 다음 접근 지점을 선택한다. 우회 가능한 지점이 없으면 보이는 대기·재배치 상태로 남으며 기본 규칙에 순간이동·벽 통과·방 이탈을 넣지 않는다. 접근 가능한 경로가 전혀 없는 적을 생성하지 않도록 방 데이터도 검사한다. 추적 중단은 HP 회복·적 삭제·방 완료로 처리하지 않는다.

약한 경직이 준비를 취소했다면 강공격 허가를 한 번 반환하고, 경직 종료 후 최신 거리·시야·쿨타임·허가를 검사해 새 행동을 선택한다. 취소 전 준비 시점으로 복귀하거나 즉시 피해를 주지 않는다. 실행 중 타격과 이미 발사된 투사체를 경직으로 되돌리지 않는 기존 규칙은 유지한다. 후딜은 약한 경직이 해제되어도 남은 시간이 끝나야 새 공격을 시작한다. 적 공격의 재사용 대기는 최초 타격 또는 투사체 발생부터 시작한다. 준비가 취소되면 재사용 대기를 시작하지 않고 경직 종료 뒤 처음부터 예고한다. 동일 조건의 공격 후보는 데이터 우선순위→attack_option_id로 정하며 실제 패턴 다양성과 선택 가중치는 후속 콘텐츠다.

## U05 전방 방어와 패링의 입사 기준

방어와 패링은 같은 입사 방향 함수를 사용하되 방어 유지 조준과 패링 창 시작 방향 고정은 D03을 유지한다. 접촉 시점의 방어 중심 위치에서 위협이 온 쪽을 가리키는 정규화 벡터를 계산한다. 근접 직접 공격은 현재 공격 판정 원점에서 방어 중심으로 향한 벡터의 반대, 투사체는 접촉 직전 실제 진행 방향의 반대, 직접 폭발은 폭발 중심에서 방어 중심으로 향한 벡터의 반대다. 발사자의 현재 위치는 날아오는 투사체의 방향을 대신하지 않는다.

발생점과 방어 중심이 겹치거나 방향 길이가 0이면 해당 공격 실행 때 저장한 전진 방향의 반대를 사용한다. 공격 전진 방향도 정의할 수 없는 중심 폭발은 전방 여부를 정할 수 없는 공격으로 처리해 방어·패링 불가로 표시한다. 충돌체의 좌우 접촉 지점만으로 전방을 바꾸지 않는다. 방어 방향과 위협 방향의 내적이 `cos(방어각/2)` 이상이면 전방이며 경계는 포함한다. 실제 방어각은 0보다 크고 180도 이하에서 데이터로 정한다.

전방이라고 모든 공격을 막는 것은 아니다. 공격의 guardable/parryable 조건, 실제 방어 구간·패링 창, 대시 무적 우선 검사와 C05 보호를 함께 적용한다. 지속 피해·바닥 주기 피해는 입사 전방을 계산해 방패로 줄이지 않는다. 폭발은 직접 피해이면서 방어 가능 표시가 있는 경우에만 전방 감소를 사용한다. 한 사건의 물리·속성 성분은 같은 입사 판정을 사용한다.

## U06 타격 연출과 시간

초기 기준에서는 타격을 이유로 전투 시뮬레이션을 정지하는 히트 스톱을 사용하지 않는다. 공격 준비·판정·후딜·공백, 대시 이동과 무적, 피격 보호, 입력 예약·재충전·쿨타임·상태 기간·틱·마나 회복·적 예고는 모두 기존 게임 시간으로 계속 진행한다. 연격 중 다수 적을 맞혔다고 실제 사이클이 길어지거나 대시 무적이 늘어나지 않는다. 메뉴·포커스 상실·보상의 전체 일시정지는 D02·D18을 유지한다.

타격감은 공격별 충격 이펙트·소리·짧은 피격 섬광·피해 표시·조절 가능한 카메라 흔들림으로 표현한다. 강도 프로필은 타격 종류와 무기 표현에 연결한다. 동일 타격의 다수 적 접촉은 대상별 피격 표현을 유지하되 공격자 소리·카메라 반응을 대상 수만큼 합산하지 않는다. 지속 피해 틱은 기본 카메라 흔들림을 발생시키지 않는다. 약한 경직은 실제 적의 행동 반응이며 연출용 정지와 혼동하지 않는다.

향후 실제 히트 스톱이 꼭 필요하면 시간 규칙 변경 질문을 새로 등록하고 전체 사이클·대시 독립 실행·입력 반응을 먼저 재검토한다. 연출 강도·길이·리소스는 후속 데이터이고 이 문서에서 임의 초 단위를 정하지 않는다.
