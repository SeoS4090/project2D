# 전투 사건과 자원 및 방 전환 기준

## 적용과 결정 경위

U07–U14 여덟 질문을 모두 기획하고 보강하라는 사용자 위임에 따른 현재 설계 기준이다. 각 답을 사용자가 개별 확정한 기록과 구별한다. 기존 기본 전투와 U01–U06을 유지하고 사건·행동·자원이 맞물리는 조건을 구체화한다. 수치·콘텐츠 다양성은 Excel 후속이며 실제 구현과 플레이 검증은 미실시다. 근거와 한계는 [[05 검증과 확장/RPG와 액션 게임 전투 규칙 비교#v0.23 사건·자원 경계의 참고와 적용 판단]]을 따른다.

## U07 동시 피해와 발동 효과의 순서

동시란 화면 프레임이 아니라 같은 실제 게임 시각이다. 시간 순으로 도착한 공격은 별도 처리한다. 같은 시각에는 D04의 만료·입력·충전·행동 시작·무적/방어 활성화까지 먼저 처리하고, 직접 접촉과 예정된 주기 틱을 하나의 최초 사건 묶음으로 수집한다. 그 묶음의 대상 방어·저항·받는 피해 보정·상태 면역·방어 자세를 계산 전에 고정한다. 피해 계산 중에는 HP·상태·회복·발동 효과를 변경하지 않는다. 공격자 피해 값은 각 공격의 기존 실행 스냅샷을 쓴다.

처리 순서는 아래와 같다.

1. 접촉 중복·범위·벽·대상 상한·무적·방어·패링·기존 피격 보호를 검사한다. 패링 반응은 U08에 따라 정리하되 이미 이 묶음에 도착한 다른 공격을 소급 제거하지 않는다.
2. 고정한 대상 상태로 피해 후보를 계산한다. 플레이어 직접 피해만 C05에 따라 감소 후 합계가 가장 큰 후보 하나를 고른다. 주기 피해는 이 직접 후보 경쟁에 포함하지 않는다. 제외한 직접 후보도 접촉 처리 기록은 남겨 같은 칼날이 재접촉으로 뒤늦게 맞히지 못하게 한다.
3. 선택한 직접 피해와 유효한 주기 피해를 대상별 `사건 시각→공격 실행 ID→효과 순번→대상 ID`로 정렬해 HP에 반영한다. 직접·주기라는 이유만으로 선후를 임의 변경하지 않는다. 이미 HP가 0인 대상의 후속 피해는 실제 HP 감소·흡혈·중복 처치를 만들지 않는다. 각 사건의 실제 HP 감소량과 첫 처치 출처를 기록한다.
4. 묶음의 사망을 확정한 뒤 살아 있는 대상에게 유효한 상태·밀려남을 적용하고 직접 피격 보호를 시작한다. 같은 묶음에 먼저 적용한 방어력 감소나 기절로 이미 계산한 다른 후보를 바꾸지 않는다. 생성이 끝난 동시 공격은 공격자 사망 때문에 이 묶음에서 소급 취소하지 않는다.
5. 살아 있는 수혜자에게 회복·흡혈을 적용한다. 같은 묶음의 치명 피해를 뒤늦은 회복으로 상쇄하지 않는다. 피해·처치에서 발생하는 추가 상태와 공격은 다음 발동 묶음으로 보낸다. 처치 기록과 보상 귀속은 공격자의 같은 시각 사망과 별개로 유지하되 죽은 공격자는 새 반격·흡혈·자동 공격을 시작하지 않는다.
6. 다음 발동 묶음은 앞 묶음이 반영된 상태를 새로 고정하여 같은 순서로 처리한다. 직접 피격 보호가 이미 생겼으면 후속 직접 발동 피해에도 적용한다. 기존 root 방문 제한·전파 깊이·대상 상한으로 발동 묶음을 유한하게 제한한다. 같은 시각의 모든 허용 발동·사망·추가 생성이 정리된 뒤에만 D18의 방 완료를 검사한다.

입력과 공격 실행 ID는 생성 순서가 안정적인 런타임 식별자다. 내용 데이터의 행 번호나 목록 순회 순서를 사건 순서로 사용하지 않는다. 무적과 보호로 차단된 접촉은 피해·상태·회복 발동을 만들지 않는다. 같은 시각의 순수 밀려남만 있는 사건은 피해 경쟁 밖에서 검사하고 C06의 갱신을 안정적인 사건 순서로 처리한다. 주기 피해는 기존대로 피격 보호·밀려남·약한 경직을 만들지 않는다.

## U08 복수 패링과 발사체 반응

한 패링 창의 모든 유효한 패링 가능 접촉은 피해·부가 상태·밀려남을 차단한다. 최초 성공 접촉만 성공 보상과 플레이어 반격 효과를 발생시킨다. 적의 공격 중단은 보상과 다른 방어 반응이므로 각각의 유효한 근접 접촉에서 해당 공격 실행 ID에 한 번 적용한다. 같은 공격의 복수 충돌체로 적 반응을 반복하지 않는다. 정예·보스도 명시된 ParryResponse만 사용한다. 반응 시 강공격 허가는 현재 점유 중인 해당 실행에 대해서만 한 번 반환한다.

서로 다른 접촉이 같은 시각에 처음 성공하면 사건 정렬 키로 최초 접촉 하나를 선택한다. 동일 묶음에 이미 생성된 다른 타격은 적 행동 중단으로 소급 취소하지 않고 각각 무적·패링·피해 후보 검사를 마친다. 패링 반응은 그 적의 이후 타격과 행동을 중단시키거나 지정 후딜로 전환한다.

발사체는 발사자의 현재 행동과 분리한다. 패링한 발사체는 C04·D15대로 대상 접촉을 기록하고 관통 예산을 소비한다. 비관통 또는 예산 소진 접촉이면 소멸하고 관통 예산이 남으면 진행한다. 패링했다고 기본 발사체를 반사하거나 발사자에게 원격 경직을 주지 않는다. 같은 발사체가 방어자를 다시 맞히지는 않는다. 공격 데이터가 명시한 접촉 폭발은 별도 공격 사건으로 생성하고 자체 방어·패링 자격을 검사한다. 패링이 모든 파생 폭발을 자동 무효화하는 규칙은 넣지 않는다.

직접 폭발의 패링은 해당 대상에 들어온 폭발 접촉만 차단하며 폭발 전체와 다른 대상의 접촉을 지우지 않는다. 폭발과 발사체의 경우 발사자 중단 프로필을 자동 실행하지 않는다. 근접 반응과 원격 접촉 처리의 구별을 HUD 피드백에도 유지한다. 대시 무적에 막힌 접촉은 패링 성공·적 중단·보상을 만들지 않는다.

## U09 기절 중 방어 종료

유효한 기절을 적용받으면 유지 중인 방어 판정을 즉시 끄고 방어 종료 동작으로 전환한다. 이는 공격 판정이 시작된 타격의 완료 규칙과 구별되는 비공격 유지 행동의 종료다. 방어 시작 준비 중이면 준비를 취소하며 아직 시작하지 않은 유지 구간이나 종료 판정을 만들지 않는다. 일반 타격·실행한 모아치기·진행 중 대시의 기존 기절 예외는 유지한다.

실제 방어를 유지하던 중 기절됐다면 종료 동작은 게임 시간으로 진행하고 기절과 종료 동작을 함께 센다. 새 행동은 기절 종료와 방어 종료 동작 중 늦은 시각 이후에만 허용한다. 두 시간을 순서대로 중복 부여하지 않는다. 기절 중 조준 입력을 읽어 커서와 마지막 입력 방향을 갱신할 수 있으나 방어각·방어 방향·새 행동을 활성화하지 않는다.

기절은 미실행 요청을 모두 폐기한다. 버튼 놓기는 입력 상태만 정리하고 종료 동작을 재시작하지 않는다. 기절 해제나 상태 면역 획득 후에도 자동 방어를 재개하지 않으며 유지 버튼을 놓은 뒤 다시 눌러야 한다. 기절로 종료한 방어를 다시 켜서 현재 공격의 남은 판정을 우회하지 못한다. 적중 검사의 최초 묶음에서 방어가 유효했다면 그 시각의 다른 후보 계산은 U07의 고정 상태를 쓰고, 기절 적용 후 묶음부터 방어를 제거한다.

## U10 대상 상한과 접촉 소비

기본 근접 범위 공격은 계속 대상 수 무제한이다. 데이터에 상한이 있는 공격만 해당 C04 적중 단위의 전체 판정 수명 동안 서로 다른 대상 수를 제한한다. 타격 순번·명시된 하위 타격·각 주기 틱은 별도 단위이고, 렌더 프레임마다 상한을 초기화하지 않는다. 투사체의 관통 예산은 D15의 별도 개념으로 유지한다.

벽 차폐·출현 중 비대상·공격의 대상 자격을 통과한 접촉 후보를 실제 접촉 시각 순으로 처리한다. 같은 시각 후보는 접촉 시점 발생점까지 거리→대상 ID로 정렬해 남은 상한만 선택한다. 먼 적을 먼저 맞힌 뒤 나중에 가까운 적이 들어와도 이전 선택을 바꾸지 않는다. 상한을 소진하면 새 대상은 같은 단위에서 피해·상태·경직을 받지 않는다.

선택된 대상이 무적·방어·패링·피격 보호 때문에 피해를 받지 않아도 접촉 한 개와 대상 기록을 소비한다. 피격 가능한 적을 찾아 차단 대상 뒤로 무제한 재시도하지 않는다. 동일 대상 재접촉은 새 상한을 소비하지 않는다. 상한 때문에 선택되지 않은 후보에는 유효 접촉 사건을 발생시키지 않는다. 대상이 죽어도 소비한 상한을 돌려주지 않는다. 대상 수 상한과 연쇄 전체 전파 대상 상한은 서로 다른 범위이며 둘 다 충족해야 한다.

## U11 비용 고정과 주기 소비

행동 시작 비용은 준비 시작 시 당시 비용 보정으로 계산해 실행 ID에 고정하고 같은 양을 예약한다. 최초 판정·투사체·효과 발생 때 이 고정 비용을 한 번 실제 소비한다. 준비 중 할인 만료·획득·기술 등급 변화만으로 예약을 올리거나 내리지 않는다. 모아치기의 기본 시작 비용은 모으기 수준과 무관하게 준비 시작 때 고정한다. 초 단위 가변 추가 비용은 시작 비용에 암묵적으로 섞지 않고 명시적인 주기 소비 효과로만 지원한다.

최대 마나 감소·명시적 마나 소모로 예약 비용을 감당할 수 없으면 D08대로 준비를 종료하고 예약을 해제한다. 실행할 수 없는 준비는 타격·시작 비용·쿨타임을 만들지 않는다. 주기 소비는 해당 주기 도래 시 현재 비용 보정을 읽고 다른 준비의 예약 마나를 제외한 가용 마나를 검사한다. 충분하면 비용을 먼저 낸 뒤 그 주기의 효과를 생성한다. 부족하면 그 주기의 효과를 만들지 않고 유지 효과를 종료하며 이후 기간의 미생성 효과를 예약하지 않는다. 이미 생성한 독립 투사체와 타격은 되돌리지 않는다.

유지 효과 종료는 정해진 종료·후딜을 진행하며 마나 회복만으로 자동 재개하지 않는다. 수동 유지 행동은 놓기·새 누르기, 자동 효과는 다음 별도의 유효 trigger가 있어야 재발동한다. 이미 시작된 쿨타임과 소비 비용은 유지한다. 마나 자연 회복은 주기 소비와 피격·공격 때문에 중단하지 않는다.

같은 시각에는 직전 시각부터 지금까지의 자연/빠른 회복을 먼저 누적하고 최대 마나를 검사한다. 그 뒤 기존 예약 유효성 검사→새 행동의 시작 비용 예약→기존 주기 소비와 자동 비용의 안정적인 효과 ID/인스턴스 ID 정렬→효과 생성 순으로 처리한다. 같은 시각 피해·처치에서 생긴 마나 회복은 U07의 피해 이후 회복 단계에 반영하며 이미 실패한 주기를 소급 성공으로 바꾸지 않는다. 전체 정지 중에는 누적·소비·주기 진행을 멈춘다.

원거리 장탄도 준비만으로 차감하지 않고 실제 첫 발사체 생성 때 발사 사건당 한 번 차감한다. 같은 한 발이 복수 탄환을 명시적으로 생성해도 기본 장탄 소비는 한 발사 사건의 비용으로 기록하며 탄환 수만큼 자동 차감하지 않는다. 준비 취소는 장탄을 쓰지 않고, 발사 후 빗나감·차단·사망은 장탄을 환급하지 않는다. 최초 발사 전 장탄 자격을 검사하고 비어 있으면 C14 자동 재장전으로 전환한다.

## U12 효과 출처와 연쇄 수명

Effect ID는 데이터의 효과 정의, logical_source_key는 `효과 소유자 ID + 부여원 종류/정의 ID + Effect ID`, execution ID는 한 번 시작한 행동, status_instance ID는 대상에게 실제 부착한 상태 인스턴스다. 동일 카드 정의의 중복 장착은 하나의 부여원과 중첩 수준으로 계산하고 카드 장수마다 별도 발동 출처를 만들지 않는다. 서로 다른 카드·무기·장인 부여원에서 같은 상태를 주면 별도 logical_source_key를 가진다.

상태 갱신 키는 대상 ID·StatusProfile ID·logical_source_key다. 같은 출처의 새 공격 실행도 기존 상태를 D12대로 갱신하며 새 실행 ID만으로 무제한 상태 인스턴스를 생성하지 않는다. 강한 값 갱신에는 새 실행의 피해 스냅샷을 사용하지만 상태 인스턴스 ID·기존 틱 일정·연쇄 방문 기록은 유지한다. 더 강하지 않은 새 부착은 현재 강한 피해 스냅샷을 덮어쓰지 않는다.

B03의 root는 시작 직접 적중과 대상의 조합으로 만든 연쇄 식별자다. 파생 공격·상태는 root와 전파 깊이를 보존한다. 같은 root의 동일 Effect ID·대상 ID 방문 제한은 부여원 종류가 달라도 공유하여 같은 효과가 서로 다른 카드 경로로 되먹임되지 않게 한다. 서로 다른 대상에서 시작한 최초 적중은 각각 root를 갖는다.

기본 지속 틱은 추가 적중 발동을 만들지 않는다. 명시적으로 주기 발동을 허용한 효과도 부착 때의 root를 상태 수명 내내 유지한다. 틱마다 root를 새로 만들거나 깊이를 0으로 초기화하지 않는다. 동일 출처 재부착으로 상태를 갱신해도 기존 상태의 root·방문 기록은 유지한다. 따라서 같은 상태에서 허용된 동일 추가 효과가 같은 대상에게 매 틱 반복되는 것으로 자동 해석하지 않는다. 상태가 끝난 뒤 새로 부착해야 새로운 root에 귀속된다. 매 주기 반복 전파가 필요한 새 콘텐츠는 별도 규칙 검토 대상이다.

root의 추적 상태는 연결된 타격·투사체·상태·후속 사건이 모두 종료됐을 때 정리한다. 이미 생성된 독립 피해는 원래 실행 스냅샷·logical source를 유지하되 죽은 소유자의 새 발동은 U07대로 막는다. 교체된 부여원은 새 trigger를 생성하지 않는다. 효과 출처·틱 시간·연쇄 기록은 런타임 상태이며 카드 콘텐츠 행이나 Effect ID 자체를 임의 변경해 표현하지 않는다.

## U13 예고 후 조건 상실

적은 공격 준비 시작 때 사거리·시야·쿨타임·강공격 허가를 검사한다. 예고가 시작된 뒤 플레이어가 사거리 밖으로 이동하거나 시야를 잃었다는 이유만으로 기본 공격을 취소하지 않는다. 정해진 준비→실행→후딜을 마치며 빗나간 공격도 최초 판정·투사체 발생에서 쿨타임을 시작한다. 플레이어는 거리·벽·대시로 공격을 피하고 후딜을 이용할 수 있다.

준비 중 조준은 실제 보이는 표적을 따라가되 시야를 잃으면 마지막 유효 관측 위치를 사용한다. 다시 보이고 아직 준비 단계면 추적을 재개한다. 추적해도 정해진 공격 사거리·범위를 늘리지 않는다. 예고는 현재 준비 방향과 공격 원점을 따라 실제 예정 범위를 갱신하고 실행 시작에서 방향·조준 목표를 고정한다. 준비 중 공격 이동은 명시된 MotionProfile만 사용하고 거리 조건을 맞추려고 무표시 순간이동하지 않는다.

실행 후 근접 위치 추종·투사체 독립 진행·벽 차폐는 기존 D14·D15를 따른다. 예고 범위가 움직이는 공격은 표시도 함께 움직이고 추적 종료를 자세·소리 등으로 구분한다. 정해진 범위 밖이나 벽 뒤의 표적에 자동 명중을 보장하지 않는다.

취소는 사망·방 종료·해당 단계에 유효한 기절/약한 경직·명시된 패링 반응에만 적용한다. 행동 선택기가 새 후보를 발견하거나 시야·거리가 변한 것만으로 취소하지 않는다. 준비 취소는 허가를 한 번 반환하고 미발생 쿨타임은 시작하지 않는다. 실행이 시작됐으면 쿨타임을 유지하고 해당 반응의 종료/후딜로 간다. 보스 전용 연계에서 다른 취소 조건이 필요하면 별도 지원 규칙과 표시를 먼저 정의한다.

## U14 방 전환과 기술 재지정

런이 이어지는 방 완료·안전한 편집·다음 방 진입은 전투 상태 전체 초기화가 아니다. 기본 유지표는 아래와 같다.

| 상태 | 방 완료 | 안전한 방·다음 방 | 런 종료 |
| --- | --- | --- | --- |
| HP·현재 마나·최대치 | 실제 값 유지, 빠른 마나 회복 전환 | HP 자동 충전 없음, 마나는 비전투 빠른 회복/전투 자연 회복 | 런 상태 제거, 다음 런 시작 규칙 사용 |
| 대시 현재 충전·충전 진행 | 그대로 유지 | 게임 진행 시간에 순차 회복, 전체 정지 때 정지 | 런 상태 제거 |
| 장탄 | 현재 잔량 유지, 무료 보충 없음 | 비어 있으면 다음 공격 입력에서 자동 재장전 | 다음 런의 시작 장탄 사용 |
| 진행 중 재장전 | 종료하고 미완료 진행도 폐기, 완료 시각이 먼저 도래한 보충만 인정 | 새 입력으로 처음부터 재장전 | 런 상태 제거 |
| 연격·공백·모으기·공격/특수행동 동작·예약 | 안전 완료 상태로 종료, 미집행 예약 마나 해제 | 새 입력으로 일반 공격 1타, 전투방 사이 종료 공백을 새로 부여하지 않음 | 제거 |
| 기술·패링·자동 효과 쿨타임 | 남은 시간 유지 | 같은 쿨타임 그룹에서 진행, 정지 때 유지 | 제거 |
| 유익한 기간 상태 | 남은 시간·효과 스냅샷 유지 | 게임 시간 진행, 안전 편집으로 부여원 제거 시 그 부여원 소유 유익 상태 제거 | 제거 |
| 적대 지속 상태·기절·밀려남·피격 보호 | D18의 적대 잔류 제거, 직접 피격 보호도 종료 | 다음 방에 넘기지 않음 | 제거 |
| 타격·투사체·피해 영역 | 적대 잔류 제거, 플레이어 소유의 현재 방 타격·투사체·영역도 종료 | 지난 방의 피해를 새 방으로 가져가지 않음 | 제거 |
| root·중복 접촉·허가·방 표적 | 종료한 사건의 기록 정리와 허가 반환, 유지 중인 유익 상태의 root는 보존 | 새 방의 실행 사건에서 새 기록 생성 | 제거 |

재장전이 중도 종료돼도 같은 잔여 탄창의 C16 공격속도 스냅샷은 유지한다. 안전 편집으로 공격속도가 바뀌어도 완료한 재장전/탄창 사이클을 우회해 진행 중 배율을 바꾸지 않는다. 새 근접 연격과 재장전 완료 후 새 탄창은 기존대로 새 배율을 읽는다. 최대치 변경은 C03·C15·D13의 증가 시 즉시 충전 없음·감소 시 제한을 유지한다.

쿨타임은 기술 배정 슬롯이나 카드 개체가 아니라 `런의 소유자 ID + CooldownGroup ID`에 귀속한다. 같은 능력의 중복 카드·다른 슬롯 배정·제거 후 같은 능력 재획득은 같은 그룹의 기존 종료 시각을 읽는다. 부여원이 사라져도 그룹 기록은 해당 런 동안 유지하고 남은 시간은 정상 게임 시간으로 흐른다. 기본적으로 서로 다른 능력은 별도 그룹이며 동일 그룹 공유는 데이터에 명시한다. 시작한 쿨타임의 길이는 시작 시 고정하고 이후 등급·감소 보정 변경은 다음 사용부터 적용한다.

안전 편집은 기존 부여원 제거·유익 상태 정리·새 능력 등록·태그/최대치 재계산을 한 번에 반영한다. 비용 예약과 전투 실행은 이때 남지 않는다. 새로 등록한 능력도 같은 쿨타임 그룹의 종료 시각을 확인하고 안전 편집을 사용 사건으로 취급하지 않는다. 실제 비용·기간·슬롯 수·새 능력 목록은 후속 데이터다.

보상·덱 편집·다음 방 선택의 전체 정지 중에는 회복·쿨타임·유익 상태 시간도 멈춘다. 장면 로딩 동안 전투 시간을 늘리지 않는다. 안전한 이동이 재개되면 남은 시간이 이어 흐른다. R02 체크포인트 저장에는 HP·마나·장탄·충전 진행·탄창 배율·유익 상태와 그 상태가 참조하는 root/방문 기록·쿨타임 그룹의 남은 시간과 RNG를 기록하고, 불러오기 때 실제 경과한 시스템 시간을 차감하지 않는다. 전투 중 종료는 마지막 확정 체크포인트로 돌아가는 기존 규칙을 유지한다.
