# 특수행동과 자원 보강 기준

이 문서는 장르 조사와 미검토 사항 해결을 위임받아 정한 v0.18 설계 기준이다. 기존 사용자 확정 규칙과 이번 보강 결정을 구분한다. 아래 새 구조 규칙은 현재 설계 기준으로 사용하며 실제 값과 콘텐츠 종류는 Excel에서 추후 정한다. 이전 문서의 상충하는 제안보다 이 기준을 우선한다. 구현·플레이 검증은 아직 수행하지 않았다.

## C11 특수행동 요청과 일반 공격 복귀

일반 공격과 특수행동·능동 기술은 하나의 공격 행동 채널을 공유하고 대시는 독립한다. 일반 공격 중 특수행동 또는 기술 요청 하나를 저장해 현재 타격의 준비·판정·후딜 완료 후 먼저 실행한다. 준비 취소로 전환하지 않는다. 현재 타격에 묶인 요청은 그 타격 완료까지 보존하고, 이미 다른 특수행동 중 받은 요청은 별도의 짧은 실시간 입력 창에서만 보존한다. 다른 요청을 새로 누르면 가장 최근 요청 하나로 교체한다.

유지형 방어·모으기는 실행 전 버튼을 놓으면 요청을 해제한다. 순간형 패링·재장전·능동 기술은 버튼을 놓아도 유효한 요청을 유지한다. 비용 부족이나 사용 불가 요청은 실행 시 폐기하고 실패 표시를 준다. 기존 일반 공격 예약 하나는 보존하되 과거의 연격 순번을 이어 쓰지 않는다. 특수행동 후 일반 공격은 1타부터 시작한다. 일반 공격 복귀 가능 시각은 마지막 일반 타격 후딜 종료+중단 대기와 특수행동 종료 중 늦은 시각이다. 연격 끝에서 이미 시작한 공백은 재시작하지 않는다. 일반 공격 예약은 복귀 시 한 번 평가 후 소비하고, 누르고 있으면 이후 정상 연격을 계속한다.

검증할 내용: 연타·유지 입력에서도 특수행동이 현재 한 타격 후 실행되고 특수행동으로 기본 공격 공백을 우회하지 않는지 확인한다.

## C12 방어와 패링

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U08 복수 패링과 발사체 반응|U08]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U09 기절 중 방어 종료|U09]].

검과 방패는 특수행동을 유지하는 동안 방어한다. 시작·종료 동작 중에는 방어 판정이 없고 실제 방어 구간에는 조준 방향의 전방 방어각을 적용한다. 공격 종류별 입사 방향과 겹침 시 기준은 [[02 전투/피해와 상태 및 적 행동 기준#U05 전방 방어와 패링의 입사 기준|U05]]을 따른다. 방어 가능한 전방 피해를 데이터 비율로 감소시키고 밀려남을 줄인다. 후방·방어 불가 공격·지속 피해는 정상 적용한다. 방어는 마나를 소비하지 않고 공격 행동 채널을 점유하며 이동 감속을 사용한다. 대시 중에도 유지하고 대시 무적 판정을 먼저 적용한다.

단검 패링은 새 누르기로 짧은 준비·성공 판정 창·후딜을 실행하고 누르고 있기만으로 자동 반복하지 않는다. 마나를 소비하지 않으며 별도 재사용 대기로 제한한다. 전방의 패링 가능 직접 공격만 성공한다. 성공하면 그 적중의 피해와 밀려남을 무시한다. 근접 적 행동 중단과 원격 접촉 반응 및 첫 성공 보상은 U08을 따라 구별한다. 정예·보스는 패링 반응 데이터가 있는 공격에만 성공하며 강공격 저항과 구별되는 명시적 예외다. 실패는 후딜을 진행한다. 패링 성공·실패 모두 대시와 독립이며 무적 접촉은 패링 성공으로 보상하지 않는다.

검증할 내용: 현재 타격 후 방어·패링 시작, 전후방 공격과 불가 표식, 대시 무적 중 패링 보상 중복을 확인한다.

## C13 대검 모아치기

특수행동 유지로 모으기를 시작하고 버튼을 놓으면 공격을 실행한다. 모으기 시간에 따른 연속 계수를 사용하고 최대 모으기에 도달하면 해당 수준을 유지한다. 실제 최대 시간과 피해·범위 증가량은 Excel에서 정한다. 실행 순간 방향을 고정하며 준비 중에는 조준을 바꿀 수 있다.

모으기·실행·후딜은 대시와 독립하며 일반 피격과 밀려남으로 취소하지 않는다. 모으기 중 일반 이동에는 능력의 감속을 적용한다. 기절이 준비를 취소할 때는 미집행 비용을 해제하고 공격이 이미 발생했으면 비용을 돌려주지 않는다. 공격을 시작하지도 않은 요청 상태에서 버튼을 놓으면 모아치기를 자동 실행하지 않는다.

검증할 내용: 대시·밀려남 중 모으기를 유지하고 준비 기절 취소와 실행 후 비용 처리가 구분되는지 확인한다.

## C14 원거리 장탄과 재장전

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U11 비용 고정과 주기 소비|U11]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U14 방 전환과 기술 재지정|U14]].

원거리 기본 공격은 근접 연격 횟수 제한 대신 장탄과 발사 동작으로 제한한다. 활과 석궁의 기본 재장전은 탄창 보충 방식으로 통일하고 실제 장탄 수를 무기 데이터로 정한다. 활은 사용자 제안대로 특수행동 버튼으로 수동 재장전하며 탄이 비면 발사 후딜 후 자동 재장전도 제공한다. 무제한 소지 탄약을 사용하고 장탄만 관리한다. 기존 활의 매 발사 후 자동 준비와 차지샷은 현재 기본 규칙에서 제외한다.

수동 재장전은 현재 한 발의 후딜 완료 후 시작한다. 가득 차 있으면 실행하지 않는다. 재장전 완료 시 한 번에 최대 장탄으로 보충하고 진행 중 기본 공격은 실행하지 않는다. 공격 요청 하나를 저장하고 누르고 있으면 완료 후 발사한다. 대시와 일반 피격·밀려남은 재장전을 취소하지 않는다. 별도 기절은 재장전을 취소하고 진행도를 버리며 현재 장탄은 보존한다. 사망·런 종료도 취소한다. 재장전·대시 동시 입력은 각 채널에서 처리하고 공격 입력은 재장전을 중복 시작하지 않는다.

검증할 내용: 탄이 없을 때 공격 유지·수동 입력·대시가 겹쳐도 장탄 보충이 한 번이고 재장전 진행을 우회하지 않는지 확인한다.

## C15 마나 소비·예약과 회복

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U11 비용 고정과 주기 소비|U11]].

기본 공격·대시·방어·패링·재장전에는 마나를 쓰지 않는다. 대검 모아치기 등 공격형 특수행동과 카드의 능동 기술은 마나를 사용한다. 패시브·자동 발동은 기본적으로 무료이며 마나 소비 효과는 데이터와 설명에 명시한다. 재사용 대기는 마나와 별도 제한이다.

예약 입력만으로 비용을 쓰지 않는다. 행동 준비 시작 시 충분한 사용 가능 마나를 확인해 비용을 예약하고 최초 공격 판정 또는 효과 발생 시 실제 차감한다. 예약된 마나는 다른 효과가 사용할 수 없으며 준비 취소·실행 불가 시 해제한다. 빗나가거나 실행 후 죽어도 차감 비용을 돌려주지 않는다. 같은 실행 ID로 비용을 두 번 차감하지 않는다. 유지형 지속 비용은 Effect에 주기 소비를 명시한 콘텐츠에만 적용한다.

자연 회복은 공격과 피격으로 중단하지 않는다. 예정 웨이브·추가 적 생성이 끝나고 살아 있는 전투 대상이 없으면 방 완료를 확정한다. 웨이브 틈과 보스 페이즈 전환은 완료가 아니다. 방 완료·다음 방 선택·비전투 방에서는 자연 회복량과 최대 마나 비례 빠른 회복량 중 큰 값을 사용하며 두 값을 더하지 않는다. 다음 전투 시작 시 자연 회복으로 돌아간다. 최대 마나 증가로 현재 마나를 즉시 채우지 않고 감소 시 새 최대치로 제한한다. 자연 회복 증가와 최대 마나 증가는 서로 별도 능력치다.

검증할 내용: 예약·취소·헛공격·연쇄 효과에서 비용 중복이 없고 웨이브 틈에 빠른 회복이 시작되지 않는지 확인한다.

## C16 공격속도 합산과 적용 범위

같은 공격속도 증가·감소 효과는 합산한다. 적용 배율은 1+총 증가율을 데이터의 양수 최소 배율과 최대 배율로 제한한다. 초기 설계에는 별도 공격속도 곱연산 종류를 두지 않는다. 최종 상·하한 수치는 Excel 후속 작업이며 초과 보너스가 적용되지 않는다는 점을 표시한다.

근접은 연격 시작 시 배율을 고정해 준비·판정·후딜·연격 간격·연결 허용 시간·중단 대기·종료 공백에 같은 배율을 적용한다. 버프 변화는 다음 연격부터 적용한다. 원거리는 탄창 사이클 시작 시 배율을 고정하고 발사 동작과 해당 사이클의 재장전을 같은 비율로 축소한다. 중도 수동 재장전은 그 사이클을 종료하며 현재 고정 배율로 재장전한 후 다음 사이클에서 새 배율을 읽는다. 이미 진행한 재장전과 공백을 능력치 변화로 다시 시작하지 않는다.

원거리의 재장전까지 포함하는 것은 전체 공격 리듬을 유지하기 위한 이번 설계 판단이며 모든 참고 게임의 공통 규칙이라는 뜻은 아니다. 기존 별도 재장전속도 제안은 현재 범위에서 제외한다. 대시·대시 재충전·특수행동·능동 기술·마나 회복·지속 피해 주기·자동 효과 쿨타임은 기본 공격속도로 줄이지 않는다. 별도 대시 재충전 속도만 C03에 따른다. 각 타격 시간에 개별 최솟값을 붙여 비율을 깨지 않으며 고속 판정은 경과 구간을 빠짐없이 검사하도록 구현한다.

검증할 내용: 같은 배율에서 근접 전체 구간과 원거리 발사·재장전 비율이 유지되고 초고속에서 판정 누락이 없는지 확인한다.
