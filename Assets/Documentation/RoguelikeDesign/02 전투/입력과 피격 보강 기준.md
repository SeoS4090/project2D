# 입력과 피격 보강 기준

이 문서는 장르 조사와 미검토 사항 해결을 위임받아 정한 v0.18 설계 기준이다. 기존 사용자 확정 규칙과 이번 보강 결정을 구분한다. 아래 새 구조 규칙은 현재 설계 기준으로 사용하며 실제 값과 콘텐츠 종류는 Excel에서 추후 정한다. 이전 문서의 상충하는 제안보다 이 기준을 우선한다. 구현·플레이 검증은 아직 수행하지 않았다.

## C01 패드와 조준 보조

기존 마우스 조준·타격 실행 순간 방향 고정과 기본 공격 준비·판정·후딜 중 이동 허용을 유지한다. 해당 이동에는 무기별 감속을 적용하고 연격 공백에는 정상 이동을 사용한다. 무기별 감속과 범위의 실제 값은 Excel에서 작성한다.

초기 출시 설계에 키보드·마우스와 패드를 포함한다. 패드는 왼쪽 스틱 이동, 오른쪽 스틱 조준이며 오른쪽 스틱이 중립이면 마지막 유효 조준을 유지한다. 처음 조준은 캐릭터의 초기 바라보는 방향이다. 입력 장치를 바꿔도 현재 타격의 실행 방향을 바꾸지 않는다.

자동 공격과 자동 대상 고정은 기본 조작에 넣지 않는다. 조준 보조는 패드의 선택 가능한 설정으로 제공하고 기본값은 꺼짐이다. 켜면 조준 원뿔 안의 가시 대상 중 조준축과 각도 차이가 가장 작은 대상을 보조하고 동률은 거리, 대상 ID 순이다. 준비 중에만 보조하며 실행 방향 고정 규칙을 유지한다. 기존 보조 대상이 살아 있고 가시 원뿔 안에 있으면 유지한다. 다른 대상의 각도 차이가 기존 대상보다 전환 여유각 이상 작아질 때만 바꾸고 기존 대상 소실 시 즉시 다시 선택한다. 원뿔 각도·전환 여유각·보조 세기는 후속 수치로 둔다.

검증할 내용: 스틱 중립·장치 전환·대상 소실에서도 실행한 타격의 방향이 바뀌지 않는지 확인한다.

## C02 대시 방향과 예약

대시 실행 순간의 이동 입력으로 방향을 결정한다. 이동 입력이 없으면 마지막 유효 이동 방향, 이동 이력이 없으면 현재 조준 방향을 쓴다. 한 대시가 시작되면 방향은 끝까지 고정하며 다음 대시는 반대 방향도 허용한다.

대시 중 다음 대시 요청 하나를 예약할 수 있다. 요청에는 입력 시각만 저장하고 방향은 다음 대시가 실제 시작될 때 다시 읽는다. 가장 최근의 새 누르기로 하나를 갱신하며 누르고 있기만으로 반복 대시하지 않는다. 예약 유효 시간은 별도 실시간 입력 창이며 공격속도의 영향을 받지 않는다. 현재 대시가 끝났을 때 유효 시간과 충전을 다시 검사해 실행하고, 충전이 없거나 만료되면 폐기한다. 충전 0에서 새로 들어온 요청은 저장하지 않는다. 공격 예약과 대시 예약은 별도로 유지한다.

검증할 내용: 왼쪽 대시 중 오른쪽 입력을 예약해 오른쪽으로 이어지는지, 오래된 입력과 충전 0 입력이 나중에 자동 실행되지 않는지 확인한다.

## C03 대시 최대 충전 변화와 회복 속도

최대 충전은 기본값과 빌드의 정수 증가량을 합산하고 최소 한 개를 보장한다. 최대치가 늘어도 현재 충전을 즉시 채우지 않는다. 기존 현재 충전과 진행 중인 충전 시간을 유지하고, 충전 타이머가 없는데 부족해졌으면 시작한다. 최대치가 줄면 현재 충전을 새 최대치까지 낮추고, 꽉 찼으면 타이머를 정지한다.

대시 재충전 속도 능력치를 별도로 지원한다. 같은 증가 효과는 합산하고 기본 공격속도와 분리한다. 충전 한 개가 시작될 때 적용 시간을 고정하고 도중 버프 변화는 다음 충전에 반영한다. 최대치 감소로 중단한 타이머의 진행도는 버리며 다시 부족해질 때 새 타이머를 시작한다. 카드 교체로 즉시 충전을 얻는 구조를 막는다. 구체적인 상·하한과 증가량은 Excel에서 정한다.

검증할 내용: 최대치를 반복 변경해도 무료 충전이 생기지 않고 부족한 충전의 순차 회복이 재개되는지 확인한다.

## C04 같은 타격의 중복 피격

근접 타격 하나의 판정 구간에서 동일 대상은 한 번만 적중한다. 키는 공격 실행 ID·타격 순번·대상 ID이며 여러 프레임, 여러 충돌체와 대시 이동으로 같은 타격이 재접촉해도 중복 피해와 경직을 주지 않는다. 다음 연격은 새로운 타격이므로 다시 적중할 수 있다. 관통 투사체도 같은 발사체로 같은 대상을 다시 맞히지 않는다.

다단 공격과 지속 영역은 데이터에 명시한 하위 타격 또는 피해 주기마다 새 적중 단위를 만든다. 무적·방어·패링으로 처리한 접촉도 해당 단위의 대상 기록에 남긴다. 같은 칼날이 대시 종료 직후 뒤늦게 피해를 주는 상황을 방지한다. 스치지 않은 타격은 기록하지 않는다.

검증할 내용: 적의 복수 충돌체와 대시 중 재접촉을 포함해 동일 단위의 피해가 한 번인지 확인한다.

## C05 피격 후 보호와 동시 판정

플레이어가 유효한 직접 피해를 받으면 짧은 직접 피격 보호를 시작한다. 보호 중에는 새로운 직접 공격의 피해·밀려남·피격 부가 상태를 적용하지 않는다. 보호로 무시한 접촉은 보호 시간을 갱신하지 않는다. 방어로 피해가 완전히 사라진 접촉과 성공 패링은 일반 피격 보호를 시작하지 않는다. 보호 시간은 Excel 후속 수치이며 대시의 전체 무적과 별도다.

같은 판정 시각에 여러 직접 공격이 접촉하면 먼저 무적·방어·패링·중복 유효성을 판단하고, 통과한 후보 중 방어·감소 적용 후 피해가 가장 큰 공격 하나를 플레이어에게 적용한다. 동률이면 밀려남 거리, 공격 실행 ID 순으로 선택한다. 그 공격의 밀려남만 적용하고 보호를 시작한다. 이후 별도 시각의 새 유효한 밀려남은 기존 사용자 결정대로 새 방향·거리·시간으로 갱신한다. 여러 방향을 합산하지 않는다. 이 동시 피해 제한은 플레이어 피격에만 적용한다.

검증할 내용: 동시 접촉 순서를 바꿔도 결과가 같고 보호 중 연속 접촉으로 보호 시간이 무한 연장되지 않는지 확인한다.

## C06 밀려남 방향과 충돌

밀려남 방향은 공격 데이터가 지정한 발생원 기준 방사 방향 또는 타격 진행 방향으로 산정한다. 방사형은 발생원에서 피격자 쪽, 방향형은 해당 타격 실행 방향이다. 위치가 겹쳐 방향을 계산할 수 없으면 타격 진행 방향을 사용한다. 새 유효한 밀려남은 현재 위치에서 시작하고 이전 잔여량은 버린다.

대시는 일반 적 몸을 통과하지만 벽·닫힌 문·고정 장애물은 통과하지 않는다. 벽에 닿으면 대시 이동만 멈추고 남은 동작과 전체 무적은 예정대로 끝난다. 밀려남은 벽에서 멈추며 잔여 밀려남을 종료한다. 벽 충돌 자체에 추가 피해나 기절을 주지 않는다. 일반 적과의 몸 충돌은 겹침을 완화하는 밀어내기로 처리하고 공격 판정과 분리한다.

검증할 내용: 좁은 통로·벽 모서리·발생원과 겹친 상태에서 관통과 방향 오류가 없는지 확인한다.

## C07 기절·사망과 강제 종료

일반 피격과 밀려남은 공격을 취소하지 않는다. 별도 기절은 기본 적 강공격의 공통 효과로 넣지 않고 명시된 특수 패턴에서만 사용한다. 기절이 들어오면 준비 중 타격은 취소한다. 이미 판정이 시작된 타격은 판정과 후딜을 마치되 새 행동을 시작하지 못한다. 기절은 적용 즉시 일반 이동·대시·특수행동 시작을 막고 모든 미실행 예약을 폐기한다. 기절 종료 후 새 입력으로 일반 공격 1타부터 시작하며 기존 공백이 남으면 기다린다.

사망·런 종료는 준비·판정·후딜과 대시를 즉시 종료하고 모든 예약을 폐기한다. 이는 전투 중 사용 가능한 취소 입력과 구별되는 종료 사건이다. 발사된 독립 투사체는 소유자가 사망했다는 이유로 공격이 되돌려지지는 않지만 런 종료 시 전투 장면과 함께 제거한다. 생존 중 기절의 종료 시각은 현재 종료 시각과 새 종료 시각 중 늦은 값으로 갱신하고 시간을 합산하지 않는다.

검증할 내용: 밀려남은 타격을 보존하고 기절은 준비만 취소하며 사망은 모든 단계를 종료하는지 확인한다.

## C08 대시 무적과 바닥·지속 피해

대시 동작 전체에는 모든 전투 피해를 무시한다. 적 근접·투사체·폭발뿐 아니라 피해 바닥과 이미 부착된 지속 피해의 해당 시각 틱도 차단한다. 차단한 피해를 대시 후 몰아서 적용하지 않는다. 상태 이상 지속 시간과 피해 주기는 계속 흐르며 대시 자체가 상태 이상을 해제하지 않는다.

직접 피격 보호는 직접 공격에만 적용하고 지속 피해와 피해 바닥의 주기에는 적용하지 않는다. 지속 피해는 밀려남·약한 경직·피격 보호를 발생시키지 않는다. 이동 불가능 영역은 충돌로 막으며 초기 설계에는 대시 무적을 무시하는 낙사나 필수 고정 피해를 넣지 않는다. 새 콘텐츠가 예외를 요구하면 별도 규칙 개정과 표시가 필요하다.

검증할 내용: 대시 중 독 틱과 바닥 틱이 차단되고 종료 후 주기가 정상 이어지며 밀려남을 유발하지 않는지 확인한다.

## C09 적 약한 경직과 강공격 저항

일반 적은 새로운 유효한 타격마다 약한 경직을 받을 수 있다. 경직의 남은 시간은 합산하지 않고 새 종료 시각과 기존 종료 시각 중 늦은 값으로 갱신한다. 일반 적의 준비는 약한 경직으로 취소할 수 있지만 이미 발생한 투사체나 실행 중 타격은 되돌리지 않는다. 고속 연격으로 일반 적을 견제하는 플레이는 허용한다.

정예·보스는 표시된 강공격의 준비와 실행 동안 약한 경직에 완전 면역을 적용한다. 후딜에는 저항을 해제한다. 보스의 위치 이동을 깨뜨리는 일반 밀려남은 면역으로 하고 별도 브레이크 능력은 초기 범위에서 제외한다. 피해·상태 이상과 약한 경직 면역을 혼동하지 않도록 별도로 표시한다. 일반 적이 계속 견제되더라도 정예·원거리 적이 압박을 만들도록 배치한다.

검증할 내용: 면역 표시 구간에는 강공격이 끊기지 않고 후딜에는 경직 저항이 해제되는지 확인한다.

## C10 다수 적 강공격과 예고

방 단위로 강공격 준비 시작 허가를 관리한다. 허용된 동시 강공격 수와 준비 시작 간격을 넘어선 적은 접근·이동·일반 공격으로 기다린다. 이미 예고한 강공격은 허가 부족을 이유로 도중 취소하거나 공격속도를 바꾸지 않는다. 보스 연계 패턴은 하나의 명시된 패턴으로 따로 관리한다.

예고는 준비 자세·바닥 경계·소리로 표시하고 색만으로 구분하지 않는다. 피해 범위와 예고 범위가 일치해야 하며 효과 장식은 위험 경계를 가리지 않는다. 추적 조준은 준비 중까지만 허용하고 실행 시 방향을 고정한다. 불가피한 위험 범위로 공간 전체를 동시에 덮지 않도록 안전 경로를 시험한다. 동시 허용 수와 예고 시간은 Excel과 플레이 검증에서 정한다.

검증할 내용: 근접·원거리·정예 혼합 방에서 보이는 안전 경로와 실제 피해 범위가 일치하는지 확인한다.
