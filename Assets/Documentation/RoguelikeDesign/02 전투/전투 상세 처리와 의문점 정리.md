# 전투 상세 처리와 의문점 정리

사용자 요청에 따라 현재 전투 문서의 의문점·누락·서로 맞물리는 예외를 검토했다. 기존 개별 확정 사항과 이번 추가 설계 판단을 구분한다. 실제 수치와 콘텐츠 다양성은 후속 작업이다.

## 읽는 순서

[[02 전투/입력과 피격 보강 기준]] · [[02 전투/특수행동과 자원 보강 기준]]의 기본 규칙을 읽고 아래 질문별 상세 처리로 이어간다. 이 문서가 해당 규칙의 경계와 처리 순서를 보강한다.

## D01 어떤 규칙이 현재 기준이며 무엇이 후속 작업인가?

기존 사용자 확정 규칙을 우선한다. v0.18 보강 기준은 이전 미검토 구조를 해결한 설계 판단이며, 이 v0.19 문서는 그 기준의 누락과 모호한 경계를 보강한다. 같은 세부 질문에서는 v0.19를 읽되 기존 사용자 확정 방향을 뒤집는 규칙을 새로 넣지 않는다.

탑다운·점프 없음·스태미나 없음·마나 자연 회복·방 완료 후 빠른 회복·연격과 공백·공격속도 전체 비례 축소·다음 일반 타격 하나 예약·대시와 공격 독립·대시 전체 무적·밀려남 중 타격 유지·새 밀려남으로 갱신·특수행동은 현재 타격 후 실행을 유지한다. 비용·시간·거리·장탄·태그 요구량·슬롯·확률·무기와 적 목록은 정하지 않는다. 공식 자료로 확인한 다른 게임의 공통 사실과 우리 게임의 설계 판단을 혼동하지 않는다.

검증할 내용: 기존 확정 규칙과 세부 문서 사이에 반대 동작이 없는지 확인한다.

## D02 입력과 게임 시간은 어떤 단위로 처리하는가?

추가 조건은 [[02 전투/피해와 상태 및 적 행동 기준#U06 타격 연출과 시간|U06 타격 연출과 시간]]을 따른다.

누르기·유지·놓기를 구별하고 동일 물리 입력이 한 처리 시각에 중복 전달되어도 한 요청만 생성한다. 일반 공격은 유지와 연타를 모두 지원하고 대시·패링·순간형 기술은 새 누르기에만 요청을 생성한다. 반복 입력은 예약 개수를 늘리지 않고 가장 최근 요청만 갱신한다.

문서의 실시간 입력 창은 공격속도로 줄이지 않는 게임 진행 시간이다. 일시정지·보상 선택·창 포커스 상실 동안에는 행동·예약 만료·회복·쿨타임·상태 이상 시간을 모두 멈춘다. 다시 열 때 누르고 있었던 버튼은 새 누르기로 취급하지 않고 한 번 놓은 뒤 새로 눌러야 행동을 시작한다. 전투방 전환은 예약을 폐기하며 입력 장치 전환만으로는 예약이나 실행된 타격을 취소하지 않는다. 기존 연결 허용 시간과 중단 대기는 공격속도로 비례 축소하는 별도 규칙을 유지한다.

검증할 내용: 창 전환과 정지·재개 때 유령 입력·예약 만료·시간 진행이 없는지 확인한다.

## D03 이동 속도와 조준 방향이 동시에 바뀌면 어떻게 하는가?

대각선 키 입력은 정규화해 직선보다 빠르지 않게 한다. 패드 이동은 중립 구간을 제외하고 스틱 크기에 따라 속도를 조정하며 조준 중립은 마지막 유효 방향을 유지한다. 기본 이동 능력치 변화는 일반 이동에 반영하고 공격·방어·모으기·재장전의 이동 배율을 그 행동 구간에만 곱한다.

대시의 방향·거리·기간은 해당 대시 시작 시 고정한다. 도중 이동속도 버프와 입력으로 이미 시작한 경로를 바꾸지 않는다. 일반 이동·대시·밀려남의 이동 벡터를 중복 합산하지 않는다. 대시 중에는 대시, 대시 밖에서 밀려남이 진행 중이면 밀려남, 둘 다 없으면 일반 이동을 사용한다. 조준은 이동과 분리하고 근접 판정의 위치 추종과 타격 실행 순간 방향 고정은 유지한다. 방어 방향은 유지 중 최신 조준을 따라가며 패링은 성공 판정 창이 시작될 때 방향을 고정한다.

검증할 내용: 대각선·패드 중립·이동 버프·밀려남 중 대시에서 속도 중복과 방향 변경 오류가 없는지 확인한다.

## D04 같은 순간의 대시·쿨타임·피격은 어떤 순서인가?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U07 동시 피해와 발동 효과의 순서|U07]].

실제 충돌 시각 순으로 판정한다. 표시 프레임 하나에 속한다는 이유로 먼저 도착한 피해를 늦은 대시로 무시하지 않는다. 같은 시각의 사건은 다음 순서로 처리한다.

1. 기존 기절·사망·행동과 보호·쿨타임의 종료 시각을 갱신한다.
2. 만료된 예약을 폐기하고 그 시각에 들어온 입력을 받는다.
3. 충전 회복과 사용 조건을 반영해 시작 가능한 대시·공격 행동을 결정한다.
4. 새 대시의 무적과 실제 방어·패링 구간을 활성화한다.
5. 적중 후보를 수집해 중복·무적·방어·패링·피격 보호를 검사한다.
6. U07의 고정 계산·피해 반영·사망·상태·회복·다음 발동 묶음 순서로 처리한다.

기간은 시작 포함·종료 제외다. 대시 시작 시각의 피격은 무적으로 막고 종료 시각의 피격은 막지 않는다. 끝나는 즉시 유효한 다음 대시가 시작되면 새 대시의 무적을 적용한다. 보호 시간과 예약 만료에도 같은 경계 정의를 쓴다. 연속 사용 중 충전은 새 대시가 실제 시작할 때 한 번만 차감한다.

검증할 내용: 종료 직전·종료 시각·새 대시 시작 시각과 충전 회복이 겹치는 사례를 각각 확인한다.

## D05 같은 순간 여러 공격을 맞을 때 방어와 효과도 모두 발동하는가?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U07 동시 피해와 발동 효과의 순서|U07]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U08 복수 패링과 발사체 반응|U08]].

플레이어 직접 피격의 동시 판정은 C05를 따른다. 후보별 예상 피해를 동일한 계산 기준으로 구하되 계산 중에는 HP 변경·회복·처치·반격·적중 효과를 발생시키지 않는다. 무적으로 차단된 후보는 패링 성공으로 바꾸지 않는다. 패링 가능한 후보는 성공 접촉으로 처리하고, 나머지 유효 직접 피해 후보에서 감소 후 피해가 가장 큰 하나를 적용한다. 동률은 밀려남 거리와 안정적인 공격 실행 ID 순이다.

패링 한 동작의 첫 성공 접촉만 성공 보상과 반격 효과를 발생시킨다. 같은 창의 나머지 패링 가능 접촉은 피해를 막되 보상을 중복 지급하지 않는다. 방어 접촉 표시와 실제 HP 피해 사건을 분리한다. 동시 피해 선택에서 제외된 공격은 적중 후 상태·흡혈·처치를 발생시키지 않는다. 대상별 치명타 판정값은 실행 ID·타격·대상에 귀속해 후보 검사 순서로 결과가 바뀌지 않게 한다. 이 제한은 플레이어 피격에만 적용하고 적이 플레이어의 다수 유효 공격을 맞는 것을 한 공격으로 축소하지 않는다.

검증할 내용: 후보 수집 순서를 바꾸거나 여러 패링 가능 공격을 겹쳐도 피해와 성공 보상이 동일한지 확인한다.

## D06 기절과 순수 밀려남은 공격·대시에 어떤 차이가 있는가?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U09 기절 중 방어 종료|U09]].

일반 피해·밀려남은 타격·예약을 유지한다. 유효한 별도 기절은 준비 중 공격·모으기·재장전을 취소하고 미실행 요청을 폐기한다. 이미 판정이 시작된 공격은 현재 판정과 후딜을 완료한다. 기절 중에는 새 이동·대시·공격 행동을 시작하지 못한다.

진행 중 대시에 기절을 외부 사건으로 부여하는 경우 대시와 무적은 예정된 종료까지 유지하지만 다음 대시 요청은 폐기한다. 대시 중 적중으로 발생할 기절은 무적으로 무시하므로 이 예외를 통해 적 공격이 대시를 끊지는 못한다. 기절 종료 이후에는 새 입력이 필요하며 기존 공백은 남은 만큼 적용한다. 준비 기절 취소 시에도 그 무기의 중단 대기를 취소 시각부터 부여해 즉시 1타 반복으로 우회하지 못하게 한다.

HP 피해가 없지만 밀려남만 발생하는 공격은 무적·직접 피격 보호와 동일한 접촉 유효성을 검사한다. 유효하면 밀려남을 갱신하되 HP 피해가 없으므로 피해 보호를 새로 시작하지 않는다. 별도 기절이 기본 강공격 전체에 자동 붙는 것은 아니다.

검증할 내용: 대시 중 외부 기절·준비 기절·순수 밀려남·기절 종료 후 재공격의 차이를 확인한다.

## D07 유지형 방어·모으기에서 일반 공격이나 다른 기술로 어떻게 전환하는가?

일반 타격에서 특수행동으로는 기존대로 현재 타격 후딜 완료 후 전환한다. 방어 유지 중 일반 공격이나 다른 기술을 누르면 요청 하나를 저장하지만 방어 버튼을 놓기 전에는 실행하지 않는다. 방어 버튼을 놓으면 종료 동작을 마친 뒤 요청을 평가한다. 종료 동작이 있으면 그것을 생략하지 않는다.

모으기 중 일반 공격·기술 입력도 한 요청으로 저장하되 특수행동을 놓아 모아치기를 실행하고 후딜을 완료한 뒤 평가한다. 일반 공격 입력만으로 모으기를 취소하거나 즉시 방출하지 않는다. 유지형 행동이 길어져 새 기술 요청의 실시간 창이 만료되면 그 요청은 폐기하지만 일반 공격 유지 입력은 복귀 가능한 시점에 다시 읽는다. 유지형 요청을 실행 전에 놓은 경우에는 시작하지 않는다.

재장전 자동 시작과 수동 요청이 같은 시점에 충돌하면 재장전 하나만 실행한다. 실행 가능한 명시적 특수행동·기술 요청을 일반 공격보다 먼저 평가하고, 사용할 수 없으면 그 요청만 폐기해 일반 공격 평가를 계속한다. 탄이 없어 선택된 일반 공격을 실행할 수 없으면 자동 재장전한다. 대시는 이 순서와 별도로 실행한다.

검증할 내용: 방어 유지·놓기·모으기 중 연타·빈 탄창의 수동/자동 요청 중첩을 확인한다.

## D08 비용 예약 중 최대 마나 감소·취소·기술 빗나감이 생기면?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U11 비용 고정과 주기 소비|U11]].

사용 가능한 마나는 현재 마나에서 미집행 예약 비용을 뺀 값이다. 예약 입력 자체에는 비용을 잡지 않고 준비 시작 시 한 실행 ID에 비용을 예약한다. 최초 판정·투사체·효과를 만드는 순간 예약을 실제 소비로 전환한다. 하나의 기술이 여러 적을 맞히거나 여러 후속 효과를 내도 시작 비용은 한 번이다.

준비 중 최대 마나 감소나 명시적 마나 소모 효과로 예약을 감당할 수 없게 되면 그 준비를 실행 불가로 종료하고 예약을 해제한다. 같은 시각의 여러 자동 마나 소비는 안정적인 효과 ID 순으로 가용량을 검사해 부족한 효과만 실패한다. 비용을 음수로 만들거나 빚으로 보존하지 않는다. 준비 취소는 예약만 해제하고 이미 소비한 비용을 회복시키지 않는다. 실행 후 빗나감·패링당함·투사체 소멸·사망은 비용을 환급하지 않는다.

능동 기술과 공격형 특수행동의 재사용 대기는 최초 판정·효과 시각부터 시작한다. 패링은 성공 창 시작부터 재사용 대기를 시작해 실패해도 제한이 적용된다. 방어·재장전은 별도 쿨타임을 도입하지 않고 동작으로 제한한다. 준비만 취소된 기술은 미집행 쿨타임을 시작하지 않는다. 재사용 대기와 마나 회복은 기본 공격속도로 줄이지 않는다.

검증할 내용: 준비 취소·최대 마나 감소·다단 기술·패링 실패에서 중복 차감과 쿨타임 우회가 없는지 확인한다.

## D09 버프가 공격 중 끝나면 피해와 효과는 어떤 능력치를 사용하는가?

타격의 준비·판정·후딜 시간은 기존의 연격·탄창 시작 시 고정한 공격속도를 사용한다. 피해용 공격력·치명타·공격자 피해 보정·모으기 수준은 타격 실행 순간에 고정한다. 시작하지 않은 다음 타격은 그 실행 시각의 값을 새로 읽는다. 같은 근접 타격의 판정 구간이나 발사한 투사체가 비행하는 동안 공격자 버프가 끝나도 해당 타격의 고정 값을 바꾸지 않는다.

피격자의 방어·저항·방어 자세·무적·받는 피해 보정은 실제 접촉 시각에 읽는다. 대상이 준비 중이나 투사체 비행 중 방어를 올렸다면 적중 때 적용한다. 공격에서 등록된 추가 효과 종류와 출처는 실행 시 고정하지만 대상 자격은 발생 시각에 검사한다. 이미 발사된 공격은 버프가 끝났다는 이유로 기본 공격으로 되돌리지 않는다. 새로운 발동 공격은 생성될 때 자기 피해 값을 고정한다.

검증할 내용: 버프 만료·대상 방어 변화·장시간 투사체 비행과 다음 연격의 피해 기준 시점을 확인한다.

## D10 피해·치명타·방어의 계산 순서는?

피해 성질·적용 방식과 성분 집계는 [[02 전투/피해와 상태 및 적 행동 기준#U01 피해 성질과 적용 방식|U01]]을 따른다. 물리·속성과 직접·지속 피해를 서로 다른 축으로 구분한다.

피해 성질은 물리 또는 속성이고 적용 방식은 직접 또는 지속이며 실제 속성 목록은 후속 콘텐츠다. 같은 종류의 공격자 증가율은 합산하고 서로 다른 명시된 피해 단계의 배율은 곱한다. 기본 공격은 고정 공격력×타격 계수, 추가 피해는 해당 효과에 지정한 기준 능력치×효과 계수로 각각 시작한다. 같은 추가 피해를 기본 타격의 합계에 다시 포함하지 않는다.

계산 순서는 원시 피해→공격자 보정→치명타→대상 방어 및 해당 피해 저항→대상 받는 피해 보정→전방 방어 감소→최종 HP 감소다. 방어는 방어력/(방어력+방어 기준 상수)로 감소율을 계산하며 상수는 데이터에서 정하고 양수여야 한다. 방어력은 음수로 만들지 않는다. 저항과 감소의 허용 상·하한은 데이터로 제한해 음수 피해를 회복으로 해석하지 않는다. 무적·패링은 피해 배율이 아니라 적중 차단이다.

치명타 가능 직접 타격은 타격·대상별 한 번 판정한다. 같은 타격이 복수 충돌체를 만나도 다시 추첨하지 않는다. 기본 지속 피해에는 치명타를 적용하지 않고 추가 효과도 명시적으로 허용한 효과만 치명타를 사용한다. 내부 HP·피해는 실수로 유지하고 UI에서만 표시 자릿수를 정한다. 매 틱 반올림 때문에 소량 피해가 사라지게 하지 않는다. 실제 HP 감소량은 남은 HP 이하이며 초과 피해와 구별한다.

검증할 내용: 치명타·방어·속성 저항·방패·소량 지속 피해·초과 피해의 적용 순서와 출처 합계가 일치하는지 확인한다.

## D11 적중·피해·처치·흡혈은 같은 사건인가?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U07 동시 피해와 발동 효과의 순서|U07]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U12 효과 출처와 연쇄 수명|U12]].

접촉은 판정 범위에 닿은 사건, 적중 성공은 무적·패링 등으로 차단되지 않은 공격, 피해 발생은 실제 HP가 감소한 사건으로 구분한다. 무적과 패링에 막힌 접촉은 적중 피해 효과·흡혈·상태 부착을 발생시키지 않는다. 방어로 최종 HP 감소가 사라진 경우 방어 접촉은 기록하되 피해 발생 효과는 발동하지 않는다. 기본 적중 발동은 실제 HP 감소가 있는 직접 타격에서 발생하도록 정의하고 별도 방어/접촉 효과는 해당 사건을 명시한다.

흡혈·피해 기반 자원 회복은 실제 HP 감소량을 기준으로 계산해 초과 피해와 무한 HP 훈련 표적을 악용하지 않는다. 훈련장은 별도 시험 수치를 보여주되 영구 재화와 발견 사건을 발생시키지 않는다. 같은 시작 타격에서 파생된 효과는 기존 root 연쇄 제한을 지킨다.

한 대상의 HP가 처음 0에 도달한 피해 사건만 처치 사건을 소유한다. 같은 시각의 최초 피해와 후속 발동 묶음은 U07을 따르고 각 묶음 내부의 유효 피해는 사건 시각→공격 실행 ID→효과 순번→대상 ID로 적용해 첫 치명 사건의 출처로 처치를 기록한다. 이미 죽은 대상의 잔여 공격은 추가 처치나 흡혈을 만들지 않는다. 처치 보상은 대상 ID와 사망 사건 ID로 한 번만 지급한다.

검증할 내용: 무적·완전 방어·초과 피해·동시 처치·추가 효과 연쇄에서 자원과 보상이 중복되지 않는지 확인한다.

## D12 상태 이상은 중첩·갱신·내성을 어떻게 적용하는가?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U12 효과 출처와 연쇄 수명|U12]].

상태 면역 획득과 해제는 [[02 전투/피해와 상태 및 적 행동 기준#U03 해제·상태 면역·피해 무적|U03]]을 따른다.

추가 조건은 [[02 전투/피해와 상태 및 적 행동 기준#U02 강화·약화 효과의 합산|U02 강화·약화 효과의 합산]]을 따른다.

상태 이상은 피해 주기·능력치 변화·이동 또는 행동 제한을 구분한다. 동일 상태와 동일 효과 출처의 재부착은 하나의 상태 인스턴스를 갱신하며 시간과 피해를 단순 합산하지 않는다. 새 종료 시각과 기존 종료 시각 중 늦은 값으로 갱신하고 피해량은 더 강한 고정 값을 유지한다. 다른 출처는 별도 인스턴스로 등록하되 상태 분류의 전체 중첩 상한을 검사한다. 상한·실제 종류와 지속 시간은 데이터 후속이다. 전체 상한에 도달한 상태에서 다른 출처가 들어오면 피해형은 고정 피해량, 능력치형은 보정의 절대 크기로 가장 약한 인스턴스를 고른다. 새 효과가 더 강할 때만 그것을 교체하고 같거나 약하면 새 부착은 실패한다. 동률의 기존 인스턴스는 남은 시간이 짧은 것, 출처 ID 순으로 선택한다. 행동 제한형은 기본 기절의 종료 시각 갱신 규칙을 쓰며 강도 비교로 임의 교체하지 않는다.

첫 피해 틱은 부착 후 해당 주기가 지난 때 발생한다. 재부착만으로 다음 틱을 즉시 당기거나 계속 미뤄 피해가 사라지게 하지 않는다. 적용받는 내성과 면역은 부착 시 검사하며 상태 부착 실패가 이미 확정된 직접 피해를 되돌리지 않는다. 대시 중 무시한 직접 공격은 상태도 부착하지 않는다. 이미 부착된 상태는 대시 중 시간만 흐르고 차단된 틱은 나중에 보충하지 않는다.

둔화는 이동속도 감소로 처리하고 대시 진행 거리와 시간을 바꾸지 않는다. 기절은 C07·D06을 따르며 새 능력의 얼림·속박 같은 이름을 자동으로 기절과 같은 규칙으로 해석하지 않는다. 그런 종류를 콘텐츠에 추가할 때 상태 프로필에서 차단할 행동을 명시한다. 초기 범위에 명세 없는 행동 제한을 넣지 않는다.

검증할 내용: 재부착·다른 출처·면역·대시·틱 직전 갱신에서 무한 지연과 몰아서 피해가 없는지 확인한다.

## D13 HP 회복과 사망·흡혈이 동시에 발생하면?

기본 HP 자연 회복은 도입하지 않는다. 마나 자연 회복과 별도로 HP는 명시된 회복 아이템·효과·방 보상만 사용한다. 회복은 최대 HP까지 적용하고 초과분을 임의 보호막으로 바꾸지 않는다. 최대 HP 증가만으로 현재 HP를 즉시 채우지 않으며 감소 시 현재 HP를 새 최대치 이하로 제한한다. 최대치 조작을 무료 회복으로 사용하지 못하게 한다.

같은 시각에 들어온 피격 피해와 그 피해에서 발생한 회복·흡혈은 피해를 먼저 확정한다. HP가 0이면 사망을 확정하고 이후 회복으로 되살리지 않는다. 사망 후 자동 회복과 처치 회복은 신규 효과를 실행하지 않는다. 부활은 초기 공통 규칙에 넣지 않고 후속 확장이다. 두 생존자의 공격이 실제로 동시에 판정 구간에 들어왔다면 서로의 사망 전 생성된 유효 타격은 같은 시각에 성립할 수 있으나 사망 이후 새 타격을 만들지는 않는다.

검증할 내용: 치명 피격과 처치 회복·흡혈·최대 HP 변화가 겹쳐도 암묵적 부활이 없는지 확인한다.

## D14 판정 범위가 벽 너머·여러 적·빠른 이동을 만나면?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U10 대상 상한과 접촉 소비|U10]].

근접 판정은 현재 캐릭터 위치를 따라가고 실행 방향은 고정한다. 판정 형태에 포함되어도 캐릭터와 피격 지점 사이를 고정 벽이 막으면 기본 근접 피해를 주지 않는다. 관통벽 능력은 초기 기본 규칙이 아니다. 판정 구간 동안 새로 들어온 대상은 맞을 수 있지만 이미 처리한 대상은 같은 타격으로 다시 맞지 않는다.

무기 범위의 기본 대상 수는 제한하지 않아 범위 안 여러 적을 함께 맞힌다. 특정 효과에 대상 상한을 명시하면 발생점까지 거리→대상 ID 순으로 선택한다. 근접 판정의 크기와 투사체의 사거리를 같은 것으로 취급하지 않는다. 대시·고속 공격·큰 이동에서도 이동 경로와 판정 시간 구간을 검사해 표시 프레임 사이의 접촉을 누락하지 않는다. 타격 판정이 준비와 후딜까지 임의로 확장되지는 않는다.

검증할 내용: 벽 뒤 적·복수 충돌체·판정 도중 진입·대시 경로와 초고속 타격의 실제 적중 대상을 확인한다.

## D15 투사체의 관통·벽 충돌·폭발·사망 후 잔류는?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U08 복수 패링과 발사체 반응|U08]].

기본 투사체는 발사 때 위치·방향·피해 값을 고정하고 이후 캐릭터 이동과 조준을 따라가지 않는다. 사거리 끝·수명 끝·고정 벽 충돌 또는 비관통 대상 접촉에서 소멸한다. 관통은 처리한 서로 다른 대상 접촉 단위로 횟수를 소모하며 무적·방어·패링으로 막힌 대상도 접촉 기록과 관통 소비에 포함한다. 같은 대상 재접촉은 다시 소모하지 않는다. pierce_count는 첫 대상 이후 추가로 통과할 수 있는 서로 다른 대상 수다. 0이면 첫 대상 접촉에서 소멸하고, 추가 통과 예산을 소진하면 다음 대상 접촉을 처리한 뒤 소멸한다.

관통 가능한 적과 벽이 같은 경로에 있으면 실제 충돌 위치 순으로 처리하고 벽 이후 적에게 적용하지 않는다. 폭발은 해당 효과가 명시한 발생 사건에서 한 번 생성한다. 범위 안 대상과 벽 차폐를 검사하고 직접 타격 피해와 폭발 피해는 별도 적중 단위로 집계한다. 기본 폭발도 벽을 통과하지 않는다. 발사자의 사망만으로 이미 발사된 독립 투사체를 삭제하지 않지만 방 완료·런 종료에는 남은 적대 투사체와 공격 영역을 제거해 보상 화면 뒤 피해를 막는다. 귀환·유도·벽 반사 같은 종류는 새 콘텐츠의 별도 동작 프로필이다.

검증할 내용: 관통 소모·무적 대상·동일 대상 재접촉·벽과 적 충돌 순서·폭발 한 번 발생을 확인한다.

## D16 적의 몸에 닿거나 적이 나타나는 순간에는 어떻게 되는가?

적 몸 접촉만으로 기본 피해를 주지 않는다. 몸 충돌은 이동 겹침 완화이고 접촉 피해가 필요한 특수 적은 공격 판정과 주기를 가진 별도 패턴으로 정의해야 한다. 기본 이동은 벽과 적 겹침을 완화하고 대시는 일반 적 몸을 통과한다. 보스의 이동 불가능한 구조물 부분은 적 몸이 아니라 고정 장애물로 표시한다.

적은 등장 위치와 경고를 보여 주는 출현 동작을 마친 뒤 공격을 시작한다. 플레이어와 겹친 위치나 닫힌 벽 안에는 생성하지 않고 가능한 위치가 없으면 생성을 지연한다. 아직 출현 동작 중인 적도 살아 있는 예정 전투 대상으로 집계해 방 완료를 막는다. 출현 중 공격 가능 여부는 공통적으로 불가로 두어 보이지 않는 적을 먼저 죽이거나 나타나는 프레임에 즉시 피해를 받는 상황을 막는다. 실제 위치·등장 시간·적 종류는 데이터 후속이다.

검증할 내용: 새 웨이브·플레이어 겹침·보스 장애물·출현 도중의 완료 판정을 확인한다.

## D17 경직 면역·패링 반응·방 단위 공격 허가가 충돌하면?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U13 예고 후 조건 상실|U13]].

추가 조건은 [[02 전투/피해와 상태 및 적 행동 기준#U04 적의 공통 행동과 경로|U04 적의 공통 행동과 경로]]을 따른다.

약한 경직 면역은 준비·실행의 경직만 막고 HP 피해·속성 저항·상태 면역을 뜻하지 않는다. 정예·보스도 명시된 패링 가능 공격은 해당 ParryResponse를 사용해 실행 중단 또는 지정 후딜로 전환할 수 있다. 패링 반응이 없는 공격은 패링 불가로 표시한다. 경직 면역을 패링 성공으로 자동 해제하지 않는다.

강공격 시작 허가는 준비 시작부터 실행 종료까지 점유하고 후딜 시작·패링 중단·사망 때 반환한다. 이미 예고된 공격은 플레이어가 공격 중이라는 이유로 자동 지연하지 않는다. 허가 부족으로 대기 중인 적은 준비 예고를 먼저 띄우지 않는다. 방 종료 때 허가와 요청을 전부 초기화한다. 동일 상태 변화 사건에서 허가를 두 번 반환하지 않는다. 일반 적 경직은 준비를 중단할 수 있지만 이미 발사된 투사체를 되돌리지 않는다.

검증할 내용: 패링·경직·사망·후딜 진입이 겹쳐도 강공격 허가 누락과 중복 반납이 없는지 확인한다.

## D18 마지막 적을 죽였지만 독·투사체·추가 생성이 남아 있다면?

추가 경계 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U14 방 전환과 기술 재지정|U14]].

방 완료는 예정 웨이브·추가 생성 조건이 끝나고 살아 있는 전투 대상이 없을 때만 확정한다. 사망한 적의 처치에서 생성되는 추가 적까지 먼저 등록하고 완료를 검사한다. 페이즈 전환과 출현 대기는 완료가 아니다.

완료가 확정되면 적대 투사체·피해 영역·플레이어에게 붙은 적대 지속 피해와 기절을 종료한다. 남은 밀려남도 종료하고 예약을 폐기한다. 이미 소비한 비용은 환급하지 않는다. 플레이어 공격과 동작은 안전한 보상 상태로 종료한다. 보상 중에는 전투 시간을 멈추고 덱·능력 변경을 한 번에 반영한다. 마나의 빠른 회복은 완료 직후부터 적용하고 보상 표시가 즉시 시간을 멈추면 다음 방 선택·안전한 이동이 재개될 때 이어 진행한다.

HP가 0인 사망을 방 완료보다 먼저 확정한다. 마지막 적과 동시에 죽으면 클리어 생존 보상으로 자동 부활시키지 않고 실패 정산한다. 처치·발견 기록은 해당 런의 정산 규칙에 따른다. 실제 완료 보상량은 여기서 정하지 않는다.

검증할 내용: 마지막 적의 소환·잔류 탄·독·동시 사망·보상 일시정지에서 완료와 사망의 결과를 확인한다.

## D19 플레이어가 실패 원인과 예약 상태를 어떻게 이해하는가?

HUD에는 현재/최대 HP·마나, 사용 가능한 마나와 예약 표시, 대시 현재/최대 충전과 다음 한 개의 회복 진행, 원거리 장탄·재장전 진행, 특수행동/기술의 준비와 쿨타임을 표시한다. 마나 부족·충전 없음·기절·재장전 중을 서로 다른 짧은 표시로 설명하고 실패 입력을 자동 저장했다는 인상을 주지 않는다.

예고는 실제 피해 범위와 일치하게 표시하고 방어·패링 불가 공격은 색 외의 형상이나 아이콘으로 구별한다. 약한 경직 면역·대시 무적·피격 보호의 표시도 구분한다. 기본 피해·치명타·차단·상태 피해는 피드백을 구분하되 피해 숫자가 위험 경계를 가리지 않게 한다. 화면 흔들림·피격 섬광·피해 숫자 강도는 옵션으로 조절한다. HUD에 내부 ID·처리 순서 같은 구현 정보를 노출하지 않는다. 실제 아이콘·색·효과 종류는 제작 후속이다.

검증할 내용: 각 실패 입력과 방어/패링 결과를 플레이어가 구분하고 다수 효과에서도 위험 예고를 읽을 수 있는지 확인한다.

## D20 기획 완료와 실제 시험 완료는 어떻게 구분하는가?

이 문서의 각 답변은 추가 설계 기준이고 검증 문장은 앞으로 구현할 시험 시나리오다. 실제 게임을 실행해 통과한 결과가 아니다. 전투의 최초 시험은 단일 타격·대시·밀려남을 함께 재현한 뒤 유지형 행동·재장전·마나·피해·상태·정예 패턴·방 완료 순으로 넓힌다.

후속 데이터는 시간·범위·배율·피해·비용·충전·쿨타임·장탄·상태 상한·적 배치·패링 창·예고·동시 허가 수·표시 리소스를 작성한다. 실제 무기·적·속성·카드 다양성은 이 규칙과 데이터 참조를 재사용해 추가한다. 새 행동 종류가 필요하면 지원되는 규칙과 허용값을 먼저 개정한다. 이번 작업에서 임의로 최종 수치나 콘텐츠 수를 정하지 않는다.

검증할 내용: 각 답변의 규칙·데이터 필드·예외·시험이 연결되어 있고 실제 시험 결과로 잘못 표시되지 않는지 확인한다.
