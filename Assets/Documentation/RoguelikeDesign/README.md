# 로그라이크 기획서

2D 탑다운 덱빌딩 로그라이크의 한국어 기획 문서입니다. Obsidian Vault를 그대로 버전 관리합니다.

현재 기획 기준은 **v0.23**입니다. 기초 전투의 규칙과 연결 조건은 개발 착수가 가능한 수준으로 정리했으며, 실제 수치·콘텐츠 다양성·게임 구현과 플레이 검증은 후속 작업입니다.

## 읽는 순서

1. `00 MOC/로그라이크 기획 MOC.md`에서 전체 방향과 문서 지도를 확인합니다.
2. `00 MOC/기본 전투 MOC.md`와 `02 전투/`에서 전투 규칙을 확인합니다.
3. `03 빌드와 무기/`, `04 마을과 성장/`에서 덱·무기·신성·성장 구조를 확인합니다.
4. `05 검증과 확장/`에서 데이터 연결과 미실시 시험을 확인합니다.
5. `06 결정과 기록/`에서 결정 경위·현재 질문·변경 이력을 확인합니다.

## Obsidian에서 열기

저장소 폴더를 기존 Vault로 열면 내부 wikilink와 MOC를 사용할 수 있습니다. `.obsidian/` 개인 설정은 공유하지 않습니다. GitHub에서는 일반 Markdown으로 열 수 있으며 wikilink 탐색은 Obsidian에서 제공합니다.

## 문서 관리

- 주제와 상태를 분리하고 규칙 결정·Excel 작업·실제 검증을 구별합니다.
- 해결한 질문은 완료 기록으로 옮기고 새로운 질문은 고유 ID로 등록합니다.
- 실제 수치와 콘텐츠 행은 후속 게임데이터 Excel 작업에서 관리합니다.
- `80 참고자료/`의 보존 원본은 현재 규칙과 구별하며 변경하지 않습니다.
- 자세한 운영 기준은 `06 결정과 기록/기획 문서 상태와 검토 종료 규칙.md`를 따릅니다.

## 포함 범위

기획 문서·MOC·문서 템플릿·기존 참고자료를 포함합니다. 게임 소스 코드와 실제 게임데이터 Excel은 아직 포함하지 않습니다.

## 다른 컴퓨터에서 이어가기

루트 `AGENTS.md`를 시작 지침으로 사용합니다. `06 결정과 기록/프로젝트 기억과 작업 인계.md`에 기획 의도와 현재 진행 상태를, `06 결정과 기록/다른 컴퓨터에서 작업 시작.md`에 환경 준비 순서를 정리했습니다.

두 기본 스킬과 참조 파일은 `.agents/skills/`에 포함합니다. 구성과 의존 도구는 `06 결정과 기록/스킬 구성과 유지.md`를 확인합니다. 저장소 사본은 프로젝트 기억과 지침을 공유하며 개인 메모리 전체나 인증 설정을 복제하지 않습니다.

## 반복 작업 스킬

기획 검토·채택 반영에는 `roguelike-design-review`, 문서 연결·상태 점검에는 `obsidian-design-audit`를 사용합니다. `.agents/skills/`에 있으며 `06 결정과 기록/재사용 기획 스킬 사용.md`에 요청 예시를 정리했습니다.
