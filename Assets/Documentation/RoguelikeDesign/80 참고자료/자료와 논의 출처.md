# 자료와 논의 출처
## 문서화의 기준

- [[80 참고자료/통합 기획서 v0.3 원본|통합 기획서 v0.3 원본]]과 원본 DOCX를 기준으로 주제 문서를 분리했다.
- 기본 전투의 후속 확정 사항은 [[06 결정과 기록/기본 전투 확정 기록|기본 전투 확정 기록]]에 연결했다.
- [브레인스토밍 기획 공유 대화](https://chatgpt.com/share/6ac5a5c0-28cc-83e8-9e08-3e75e0eba2f3)는 원래 논의의 참고 링크다.
- [[80 참고자료/첨부/새로운 5.txt|브레인스토밍 답변 모음]]은 사용자가 제공한 원문 참고자료다.

## 적용 우선순위

후속 대화에서 확정하거나 변경한 결정이 이전 초안보다 우선한다. 단순한 제안과 예시 수치는 사용자 채택 전에 확정으로 취급하지 않는다. 살아 있는 종교의 실제 숭배 신격 제외 원칙은 구체적 콘텐츠 채택에 적용한다.

## 보존본과 현재 작업 문서

참고자료와 보존본은 출처 확인에 사용한다. 현재 규칙은 각 주제 문서에서 수정하고 변경 이력을 남긴다. Obsidian 분리 이후 문서 개정이 자동으로 이전 DOCX에 반영되는 것은 아니다.
