# 런과 훈련장 보강 기준

이 문서는 장르 조사와 미검토 사항 해결을 위임받아 정한 v0.18 설계 기준이다. 기존 사용자 확정 규칙과 이번 보강 결정을 구분한다. 아래 새 구조 규칙은 현재 설계 기준으로 사용하며 실제 값과 콘텐츠 종류는 Excel에서 추후 정한다. 이전 문서의 상충하는 제안보다 이 기준을 우선한다. 구현·플레이 검증은 아직 수행하지 않았다.

근거와 적용 판단: [[05 검증과 확장/2D 핵앤슬래시 장르 조사|장르 조사]] · 질문별 추적: [[기획 검토 완료 기록|해결 목록]]

## R01 방 진행과 보상

공간 계층은 스테이지→맵→방이다. 초기 진행은 앞으로 갈 후보 방을 표시하고 하나를 선택해 합류하는 분기 구조다. 완료한 방으로 되돌아가 보상을 반복 획득하는 구조는 제외한다. 각 전투 방은 완료 사건당 카드 선택과 런 재화를 한 번 제공한다. 엘리트는 위험과 보상 등급을 높이고 보스는 스테이지 완료와 영구 보상을 제공한다. 카드 후보에는 현재 무기 호환·빌드 관련·범용 선택을 함께 제공하며 정확한 비중·수급·가격은 Excel에서 정한다.

대장간과 성소 접근은 진행 구조에 보장하고 성소는 필요한 기본 성장 선택 이후에 배치한다. 상점과 HP 회복은 선택 경로로 두며 마나 회복을 구매 필수 요소로 만들지 않는다. 동일 후보 중복은 제외하고 풀 부족 시 서로 다른 범용 후보로 보충하며 선택 가능한 후보가 전혀 없으면 런 재화 보상으로 대체한다. 보상·덱 편집·다음 방 선택 중에는 싱글플레이 전투 시간을 정지한다. 새 방 진입 직후 입력을 강제로 공격·대시로 이어 실행하지 않고 새 입력을 받는다. 협동은 후속 확장이다.

검증할 내용: 분기 경로 모두에서 대장간·성소 접근이 가능하고 완료·재진입·로드로 같은 방 보상이 중복 지급되지 않는지 확인한다.

## R02 정산·영구 성장과 저장

체크포인트의 전투 상태 유지와 남은 시간은 [[02 전투/전투 사건과 자원 및 방 전환 기준#U14 방 전환과 기술 재지정|U14]]를 따른다.

재화는 런 재화와 영구 재화로 구분하고 실제 명칭·종류는 콘텐츠 데이터에서 정한다. 카드·무기 제작·선택 신성·일시 재화는 런 종료 시 초기화하고 발견·도감·해금·영구 능력치는 유지한다. 사망과 포기는 같은 실패 정산 비율, 클리어는 성공 정산과 추가 보상을 적용하며 비율·금액·성장 상한·비용은 Excel에서 정한다. 영구 재화도 런 중 미정산분과 마을 보유분을 구분하고 정산 ID로 한 번만 이체한다.

안전한 방 완료와 선택 결과 확정 시 런 상태를 저장한다. 전투 도중 종료하면 마지막 확정 상태에서 해당 방을 다시 시작하며 같은 방의 전투 RNG와 보상 후보를 재사용한다. 아직 확정하지 않은 선택은 정산·획득으로 기록하지 않는다. 이어하기와 포기는 구분하며 중단 저장만으로 실패 정산을 실행하지 않는다. 정산 완료 기록과 저장을 함께 처리해 중복 지급을 막는다.

만신전은 신성 발견·조건 도감·후속 해금, 별도 성장 시설은 기존 확정 대상인 HP·방어·공격·공격속도·치명타·시작 아이템 등 수치 성장을 담당한다. 성장 초기화는 안전한 마을에서 소비 영구 재화를 환급하고 출발 전에만 허용한다. 새 해금은 시작 선택지와 보상 풀에 반영하되 빌드 관련·범용 보상 구분을 유지한다. 보상 슬롯 수 자체의 영구 증가는 초기 범위에서 제외한다. 무성장 상태로도 핵심 공략이 가능해야 한다.

검증할 내용: 사망·포기·클리어·강제 종료·이어하기를 반복해도 미정산 재화가 두 번 지급되지 않고 확정 선택이 유지되는지 확인한다.

## R03 훈련장 해금·과제·불러오기

훈련장은 첫 탑 진입 전에 조작 안내와 함께 연다. 해금한 무기·카드·장인·신성을 자유 시험하며 미해금 콘텐츠는 체험 범위로 기본 제공하지 않는다. 비용을 소비하지 않는 시험 상태를 사용하고 실제 덱·영구 재화·발견 기록을 변경하지 않는다. 훈련 과제는 이동·대시·연격·무기 능력·보상 선택을 안내하고 완료 표식만 남긴다. 반복 공격이나 과제 반복에 영구 재화를 주지 않는다.

최근 런과 저장 프리셋은 무기 ID·카드 ID와 중복 수·기술 배정·강화 ID·신성 ID 및 단계·영구 능력치 적용 여부를 기록한다. 불러올 때 현 데이터 버전과 해금·호환·슬롯을 다시 검증하고 누락 ID는 제외 사유를 보여 준다. 실전 시작 장비로 그대로 복제하는 기능과 구별한다. 초기화는 HP·마나·대시 충전·상태 이상·예약·표적·측정을 시험 시작 상태로 되돌린다.

측정은 시작·종료를 직접 지정하고 첫 유효 피해부터 종료까지의 경과 시간에 공백·이동·재장전을 포함한다. 총 피해·단일 최대 피해·평균 DPS·최근 구간 DPS·피해 출처별 합계를 제공하고 구간 길이는 데이터로 관리한다. 실제 타격 피해 이벤트만 합산하며 치명타 추가분과 자동 효과를 이중 합산하지 않는다. 기본 시험은 방어 없는 무한 HP 표적과 다수 표적, 이후 방어·상태 저항 표적으로 넓힌다. 공격 패턴 시험과 자유 DPS 시험을 분리한다.

검증할 내용: 훈련장 저장·불러오기·초기화가 영구 상태를 변경하지 않고 실전과 같은 피해 이벤트로 같은 측정 결과를 내는지 확인한다.

## R04 반복 도전의 서사와 콘텐츠 경계

2030년 지구, 이세계 신의 침략, 검은 탑 등 기존 확정 세계관을 유지한다. 침략자는 지구 신화의 실제 신격을 가져오지 않는 오리지널 이세계 신으로 하고 목적은 지구를 자신의 영역으로 고정해 편입하는 것이다. 검은 탑은 그 차원 고정 장치다. 주인공은 거점으로 모인 생존자이며 모루 조각과 공명해 신화의 힘을 무기에 담는다.

탑 결계로 신화 존재의 직접 진입이 제한돼 장인이 모루·무기를 매개로 제작 양식을 전하고 신성은 덱 조건에 맞는 권능을 전한다. 귀환 인장이 기억과 육체를 거점에 재구성해 실패 후 발견·성장은 유지되지만 탑에 종속된 카드·각인·일시 권능은 사라진다. 귀환은 세계 시간을 되돌리지 않는다. 인장 재구성에는 시간이 필요해 침략 상황이 진행된다는 서사적 대가를 두되 초기 플레이에 숨은 실시간 패배 타이머나 능력치 손실을 붙이지 않는다.

런 클리어는 탑의 고정 핵 하나를 파괴하며 추가 핵과 침식 구역이 후속 도전을 설명한다. 초기 결말은 첫 지역의 핵 파괴와 거점 방어 성공으로 완결하고 잔여 탑은 확장 여지로 남긴다. 위치·인물 이름·대사·신화권별 적은 임시 콘텐츠 ID로 작성해 추후 콘텐츠 데이터에서 구체화한다. 현존 숭배 신격 제외라는 사용자 원칙을 유지하고 검토되지 않은 실제 신격 이름을 새로 확정하지 않는다.

검증할 내용: 사망과 클리어 뒤 무엇이 남는지, 장인·신성의 역할 차이가 시작 안내와 도감에서 일치하는지 확인한다.
