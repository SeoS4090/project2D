# 덱과 성장 보강 기준

이 문서는 장르 조사와 미검토 사항 해결을 위임받아 정한 v0.18 설계 기준이다. 기존 사용자 확정 규칙과 이번 보강 결정을 구분한다. 아래 새 구조 규칙은 현재 설계 기준으로 사용하며 실제 값과 콘텐츠 종류는 Excel에서 추후 정한다. 이전 문서의 상충하는 제안보다 이 기준을 우선한다. 구현·플레이 검증은 아직 수행하지 않았다.

## B01 덱·아이템과 장착·교체

전투 연결 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U12 효과 출처와 연쇄 수명|U12]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U14 방 전환과 기술 재지정|U14]].

덱은 현재 런에서 장착한 아이템 카드의 집합이다. 같은 아이템과 카드를 별도 효과로 이중 장착하지 않는다. 손패를 뽑아 매 공격마다 소모하는 규칙은 초기 범위에 넣지 않는다. 주무기는 덱과 별도이며 능동 기술은 장착한 카드 중 지정해 사용하고 지정 자체는 슬롯을 추가 소비하지 않는다. 슬롯 용량·능동 지정 수·카드 중복 상한·등급별 목록은 Excel에서 정한다. 같은 카드의 각 장은 슬롯을 차지하고 고유 카드는 중복 장착하지 못한다.

덱이 가득 차면 새 카드를 포기하거나 장착 카드와 교체한다. 포기·제거는 런 재화로 분해하고 수급량은 데이터화한다. 별도 예비 보관함은 초기 범위에서 제외한다. 교체·제거·능동 기술 지정은 전투 완료 후 안전한 방에서만 허용한다. 주무기는 런 중 교체하지 않고 훈련장에서 비교한다. 따라서 런 중 호환하지 않는 무기 카드가 남는 상황을 만들지 않는다. 같은 카드 수치 효과는 명시된 합산 규칙을 따르고 같은 발동 효과는 중첩 수준 하나로 계산한다. 등급은 등장과 효과 분류이며 자동 태그 보너스가 아니다.

검증할 내용: 슬롯이 찬 상태에서 포기·교체·중복·고유 제한과 효과 이중 등록을 확인한다.

## B02 태그 집계와 신성 유지

태그는 현재 장착한 무기·카드·장인 강화의 TagGrant에서 합산한다. 획득 이력은 발견 기록일 뿐 현재 점수가 아니다. 교체·재단련·제거 후 관련 태그와 권능 활성 여부를 한 번에 재계산하고 확인 화면에서 변화를 미리 보여준다. 무기 분류·속성·상태 이상·행동·신화 양식은 분리하며 장인 양식이 원래 무기 태그를 지우지 않는다.

진입·유지 점수는 기본 카드·무기·장인 강화에서 읽고 신성 자체와 전용 카드가 자기 진입 조건을 만들지 못하게 한다. 전용 카드는 모든 신성의 진입·유지 점수에서 제외해 서로 조건을 떠받치는 순환도 막는다. 선택 신성의 조건을 잃으면 권능과 전용 효과를 비활성화하되 선택·성장·발견 기록은 보존한다. 조건 회복 시 재활성화하고 일반 카드 효과는 유지한다. 점수·중복 상한·조건 요구량은 Excel 후속 값이다.

검증할 내용: 태그 제거와 복구를 반복해도 권능이 중복 등록되지 않고 전용 카드가 순환 자격을 만들지 않는지 확인한다.

## B03 시너지 연쇄와 대상 판정

전투 연결 기준: [[02 전투/전투 사건과 자원 및 방 전환 기준#U07 동시 피해와 발동 효과의 순서|U07]] · [[02 전투/전투 사건과 자원 및 방 전환 기준#U12 효과 출처와 연쇄 수명|U12]].

효과는 기본 타격 적중·추가 효과 적중·처치 등 허용된 사건을 구분한다. 한 시작 적중에서 파생된 효과는 공통 root ID를 공유하고 동일 효과·동일 대상은 같은 root에서 재발동하지 않는다. 명시된 효과만 추가 효과 적중을 받아 연쇄하며 전파 깊이와 대상 수는 데이터 상한을 둔다. 기본 타격 하나가 여러 적에게 적중하면 대상별 root를 구분한다.

직접 타격·추가 피해·지속 피해의 출처를 분리하고 추가 피해를 다시 기본 피해로 중복 집계하지 않는다. 관통은 투사체 접촉 대상으로, 폭발은 발생점의 범위 대상으로 적용한다. 범위가 있다는 이유로 투사체 경로 전체에 즉시 피해를 주지 않는다. 효과 추가는 지원된 trigger·target·operation 조합을 사용하며 새로운 행동이 필요하면 동작 규칙부터 확장한다.

검증할 내용: 출혈·번개·처치 연쇄를 조합해도 자기 재발동과 무한 순환이 없고 실제 접촉 대상만 피해를 받는지 확인한다.

## B04 무기 성장과 신화 대장간

별도 무기 경험치나 카드 획득 수로 자동 숙련 레벨을 올리는 체계는 초기 범위에서 제외한다. 카드가 전투 성향을 만들고 대장간이 제작 분기를 선택한다. 제작은 기본 무기→신화 양식→기능 강화로 구성하고 신성 완성 외형을 별도의 자동 수치 단계로 더하지 않는다. 스테이지마다 대장간 접근을 보장하고 첫 양식 부여는 무료로 빌드 변화를 보장한다. 이후 기능 강화와 재단련에는 런 재화를 사용하며 비용·후보 수·스테이지 규모는 Excel에서 정한다.

첫 대장간은 해금한 장인 중 선택하고 이후에는 같은 양식의 장인을 따른다. 다른 장인의 양식 중첩은 확장으로 둔다. 기능 강화 후보에는 무기 호환·현재 태그를 검사하고 부족하면 사용할 수 있는 범용 분기를 제공한다. 재단련은 같은 단계의 분기 하나를 교체해 이전 효과·태그를 제거하고 새 효과를 적용한다. 양식의 무제한 되돌리기는 제공하지 않는다. 신성 완성 후에도 같은 단계의 재단련만 허용하며 새 제작 단계를 자동 추가하지 않는다. 마을은 도감·해금·시작 무기 선택을 맡고 런 강화는 종료 시 초기화한다.

검증할 내용: 태그가 부족해도 무료 양식 부여가 가능하고 재단련으로 효과·태그가 누적되지 않는지 확인한다.

## B05 신성 선택·성장·교체

초기 런에는 주 신성 하나만 선택하고 보조 신성과 복수 조합은 후속 확장이다. 성소에서 현재 조건을 만족한 해금 권능을 제시하고 최초 수락은 무료다. 거부·보류·조건 미달은 범용 보상으로 대체하고 다음 성소에서 다시 판정한다. 신성 미완성 빌드도 공략 가능해야 한다. 발견은 선택 시, 각성은 서로 다른 전용 카드 장착 조건을 성소에서 만족할 때, 완성은 전용 카드와 보스 처치 조건을 성소에서 함께 만족할 때 판정한다. 구체 요구량·보스 ID와 후보 수는 데이터로 정한다.

각성 전에는 성소에서 다른 자격 신성으로 교체할 수 있다. 허용 교체 횟수는 데이터로 제한하고 각성 후는 런 종료까지 유지한다. 교체 시 이전 전용 카드는 범용 후보로 교환하거나 분해하는 선택을 바로 제공해 쓸 수 없는 카드가 슬롯을 막지 않게 한다. 교환은 기존 등급에 맞는 후보를 사용하며 새 신성 전용 카드를 무상 확정 지급하지 않는다. 기록된 성장 단계는 조건 이탈 시 보존하지만 이전 신성의 효과를 새 신성에 계승하지 않는다.

선택 후 카드 보상에는 아직 보유하지 않은 전용 카드를 우선 제시할 수 있도록 보장 슬롯을 배정한다. 풀 부족·완성 후에는 빌드 관련과 범용으로 대체한다. 해금 풀이 넓어져도 조건을 만족할 후보를 제공하고 보상 순서와 슬롯 용량으로 완성 가능성을 검증한다. 미발견 권능은 이름을 숨길 수 있지만 필요한 태그와 효과 설명은 숨기지 않는다. 장인 양식은 신성을 하나로 고정하지 않는다.

검증할 내용: 기본 덱만의 공략, 조건 이탈·회복, 각성 전 교체와 전용 카드 부족 시 대체 보상을 확인한다.
