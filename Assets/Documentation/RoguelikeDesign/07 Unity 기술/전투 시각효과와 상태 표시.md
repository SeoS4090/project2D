# 전투 시각효과와 상태 표시

## 사건과 유지 상태를 구분한다

휘두르기·명중·패링 섬광은 한 번의 사건이다. 슈퍼아머·방어·무적·독은 유지 상태다. 유지 상태는 시작/종료 이벤트만 받지 않고 현재 상태 스냅샷과 대조할 수 있게 한다. 늦게 View가 연결되거나 풀에서 나와도 올바른 표시를 복구한다. 표현은 전투 결과를 읽으며 색·셰이더의 켜짐으로 실제 면역을 판정하지 않는다.

## 공격·명중 표현

첫 프로토타입은 픽셀 스타일의 Sprite 시트 슬래시와 짧은 입자·음향을 추천한다. 무기 궤적 전체를 TrailRenderer로 대체하면 임의 각도·폭·픽셀 품질과 시간 배율이 달라질 수 있으므로 필요 무기에서 비교한다. 프레임 재생·곡선·발생 위치를 ActionVisual에 묶는다. 슬래시는 실행 구간에 대응하고 활성 범위를 설명하지만 장식 Sprite의 알파를 피해 판정으로 사용하지 않는다.

실제 유효 적중 사건에는 접촉 위치·방향·대상 ID·결과·공격 실행·이펙트 키를 넘긴다. 명중·방어·패링·무적 차단·치명타는 결과별 표현을 사용한다. 휘두르기는 빗나가도 발생하고 명중 연출은 접촉 결과에서 발생한다. 다수 적의 개별 작은 피격 효과는 유지하되 큰 카메라 반응·큰 소리는 공격 사건별로 제한하는 표현 정책을 검토한다. 기본 전투 시간 정지는 도입하지 않는 U06을 유지한다.

## 상태 표시의 의미

| 실제 상태 | 추천 표현 | 의미의 경계 |
| --- | --- | --- |
| 약한 경직 면역, 통칭 슈퍼아머 | 몸체 외곽선 + 방패형 상태 아이콘/준비 자세 | 피해 무적·모든 상태 면역으로 해석하지 않음 |
| 대시 무적 | 잔상·짧은 밝기 변화 | 무적 시작/종료는 대시 논리 상태가 결정 |
| 피격 보호 | 별도 보호 표시·점멸 후보 | 슈퍼아머와 다른 아이콘/패턴 |
| 피해 반응 | 순간 플래시·작은 몸체 흔들림 | 면역 외곽선을 숨기지 않고 게임 좌표 유지 |
| 패링 성공 | 접촉 섬광·고유 음향 | 여러 차단의 보상 1회 규칙과 구별 |
| 적 강공격 준비 | 자세·바닥 범위·소리 | 준비 중 갱신, 실행 방향 고정 시 표시도 일치 |
| 독·감속 등 | 상태 아이콘·제한된 부착 효과 | 높은 우선순위 위험 경계를 가리지 않음 |

정예·보스 강공격의 준비·실행 동안 약한 경직 면역, 후딜 해제라는 C09를 표시한다. 보스의 일반 밀려남 면역은 별도 상태다. `SuperArmor` 하나로 모든 방어 권능을 뭉뚱그리지 않는다. 패링 불가·피해 무적·경직 면역을 각각의 상태 플래그와 표현 키로 연결한다. 색만으로 구분하지 않는다.

## 외곽선 셰이더의 첫 설계

Sprite의 알파 주변을 샘플링해 바깥 경계를 표시하는 Sprite 호환 셰이더를 후보로 삼는다. 유닛별 현재 상태는 StatusVisualController에서 합성해 넘긴다. 권장 초기 범위는 단일 Body Sprite의 외곽선이다. 여러 Body 파츠와 무기까지 하나의 바깥 실루엣으로 감싸려면 합성 마스크·별도 렌더 대상·추가 패스가 필요할 수 있으므로 T02에서 비용과 아트 요구를 비교한다. 각 파츠마다 외곽선을 켜면 파츠 사이 내부 경계도 강조될 수 있다.

외곽선이 Sprite 사각형 밖으로 나가면 기본 메시 경계에서 잘릴 수 있다. 원본 Sprite의 투명 여백과 Full Rect 또는 확장 메시 범위를 함께 검증한다. FullRect는 지정한 Sprite 크기의 사각 메시이며 투명 여백을 자동 추가하지 않는다. [Unity FullRect](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/SpriteMeshType.FullRect.html)

Sprite Atlas의 이웃 픽셀을 샘플링하지 않도록 로컬 Sprite 영역과 atlas UV를 처리한다. 샘플 영역 밖 알파는 투명으로 취급하고 Outline 두께와 원본 여백·atlas 간격·회전 패킹·Tight 설정을 함께 검증한다. 초기에는 회전 패킹과 Tight 경계 최적화를 보수적으로 제한하는 후보를 비교한다. atlas padding만 늘려 메시 밖 잘림이 해결된다고 가정하지 않는다.

두께 단위는 아트 픽셀과 화면 픽셀을 구분한다. PPU·출력 배율·Sprite 스케일·미러·회전에서 같은 의미의 두께를 유지하는지 확인한다. 외곽선은 어두운 조명에서도 식별 가능한 합성 방식을 검토하고, 몸체 Sprite Lit 기능·색·알파·마스크·정렬 호환을 확인한다. 초기에는 단순한 Sprite 셰이더로 시작하고 전체 화면 외곽선 Renderer Feature는 필요한 합성 실루엣의 요구가 확인된 뒤 검토한다.

## 여러 표시의 합성

여러 시스템이 같은 머티리얼 색을 덮어쓰지 않게 상태 표시 관리자 하나가 파라미터를 조합한다. 상태 유지 표시·몸체 피격 플래시·독 색·투명도·사망 페이드의 채널을 분리한다. 예를 들어 슈퍼아머 중 피격돼도 Body 플래시만 바꾸고 면역 외곽선·아이콘을 유지한다. 같은 상태를 여러 부여원이 유지할 때 하나가 끝났다고 전체 표시를 끄지 않고 최종 유효 상태를 읽는다.

공유 머티리얼을 유닛별로 직접 수정하지 않는다. 초기 실험에서는 상태별 공유 머티리얼 변형과 MaterialPropertyBlock을 비교한다. MPB는 유닛별 값을 전달할 수 있지만 공식 문서상 SRP Batcher와 호환되지 않으므로 성능상 항상 유리하다고 정하지 않는다. SpriteRenderer의 해당 Unity/URP 경로에서 실제 배치·CPU·GPU·메모리를 측정한다. [Unity MaterialPropertyBlock](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/MaterialPropertyBlock.html)

## 예고·풀·품질

바닥 위험 경계는 HitShape와 동일한 범위 정의를 읽는다. 준비 중 조준·원점 변화와 실행 고정을 따라가되 장식 입자가 경계를 가리지 않게 한다. 물체 가림과 벽 차폐의 복잡한 형태까지 표시가 설명하는지 시험한다. 예고·실행·해제의 변화가 플레이어에게 보이고 취소·사망에서 제거돼야 한다.

캐릭터 부착 효과, 실행 동안 유지 효과, 독립 투사체 효과, 접촉 위치 효과에 각각 수명·소유권을 부여한다. 풀 재사용 시 이전 대상·재생 시간·scale·flip·Sorting·MPB·잔상·입자를 초기화한다. VFX 품질을 낮추더라도 위험 예고·상태의 의미·피해 결과는 유지한다. 장식 VFX 수를 제한하는 것과 논리 투사체/피해를 누락하는 것을 구분한다.

## 표현 검증

- [ ] 슈퍼아머가 준비·실행 시작/후딜 해제에 맞춰 켜지고 꺼진다.
- [ ] 무적·패링 불가·경직 면역을 구별할 수 있다.
- [ ] 피격 플래시·독·슈퍼아머 동시 적용과 부분 해제에서 표시가 복구된다.
- [ ] atlas 경계·메시·투명 여백·방향·확대에서 외곽선 잘림과 이웃 번짐이 없다.
- [ ] VFX가 보이지 않거나 풀 대여가 실패해도 실제 피해는 동일하고 필수 표시가 대체된다.
- [ ] 일시정지·사망·방 전환·풀 반환 후 예고·외곽선·잔상이 잘못 남지 않는다.
