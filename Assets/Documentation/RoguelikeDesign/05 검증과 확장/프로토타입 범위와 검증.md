# 프로토타입 범위와 검증

## v0.18 현재 적용 기준

기획 구조를 해결한 뒤의 제작 검증 순서다. 기존 시험 예시의 실제 수치는 Excel에서 정한다. 실제 게임을 실행한 시험 결과가 아니다.

1. 단일 방에서 일반 공격·대시·피격·입력 예약을 검증한다.
2. 대검·단검·검과 방패·원거리 능력을 단계적으로 추가해 행동 전환과 자원을 검증한다.
3. 일반·원거리·정예를 섞어 경직 저항과 강공격 조율·가독성을 검증한다.
4. 한 스테이지 경로에서 보상·태그·대장간·성소·교체를 검증한다.
5. 런 종료·이어하기·정산과 훈련장 프리셋을 검증한다.

## 처음 검증할 범위 설계안

첫 프로토타입은 전투와 빌드를 시험하는 훈련장부터 구성하는 설계안이다. 캐릭터 조작 → 전투와 무기 → 피해 및 효과 → 훈련장과 허수아비 → 인벤토리 → 연쇄 시너지 순서로 검증한다. 이후 적, 방, 맵과 스테이지, 보상, 던전 런과 마을을 연결한다.

초기 규모의 기준안은 캐릭터 1종, 무기 2종, 스테이지 1개, 방 6종, 일반 몬스터 5종, 엘리트 2종, 보스 1종, 아이템 30개, 카드 20개, 빌드 아키타입 4종이다. 종류별 구성과 제작 순서는 조정 가능하다. 신화 시스템 비교는 창과 망치, 번개, 두 장인 양식부터 검증할 수 있다.

앞서 제안된 신성 4종 범위는 제우스, 토르, 아레스, 아르테미스에 해당하는 연쇄 번개, 번개 강타, 출혈 근접, 치명타 원거리의 비교다. 실제 이름은 콘텐츠 원칙에 맞춰 선택하며, 4종 전체를 초기 필수 범위로 확정하지 않는다.



## 검증 기준 설계안

- 선택과 변화: 카드 획득, 장인 강화와 신성 획득의 차이를 플레이어가 이해한다.
- 빌드 진입: 태그 진행도를 읽고 다음 보상에서 필요한 선택을 판단할 수 있다.
- 빌드 차이: 번개 창과 망치의 공격 흐름이 다르며, 연쇄 발동의 피해 출처를 훈련장에서 확인할 수 있다.
- 성장 경계: 런의 카드와 강화가 초기화되고 도감과 해금은 유지된다.

## 기본 전투 검증

누르고 있기와 연타가 동일한 연격을 이어 가는지, 연타해도 다음 타격 하나만 예약되는지, 연결 시간 안팎에서 이어짐과 1타 재시작이 구분되는지 확인한다. 중단 대기와 연결 시간이 겹쳐 계산되고 종료 공백을 입력으로 건너뛰지 못하는지도 시험한다.

공격속도 변화 전후의 전체 사이클과 타격 수를 비교하고, 첫 타격만 반복하거나 일부 연격을 반복하는 방식이 완주보다 지나치게 유리하지 않은지 확인한다. 마나 자연 회복, 방 전투 종료 후 빠른 회복, 아이템과 권능의 회복력 및 최대 마나 증가도 시험 항목으로 둔다.

## 확정한 조준과 이동의 시험 기준

[[02 전투/조준과 이동 설계안|조준과 이동 규칙]]을 기준으로 다음을 시험한다. 이는 시험 계획이며 실제 시험 완료 기록이 아니다.

- 반대 방향 이동과 조준, 준비 중 조준 변경 및 실행 후 방향 고정.
- 다음 타격의 최신 조준 반영과 캐릭터 중심에서 마지막 유효 방향 유지.
- 이동하는 근접 판정의 방향 유지와 발사한 투사체의 독립적인 진행.
- 준비·판정·후딜 중 이동과 감속, 이동 입력만으로 타격이 취소되지 않는 처리.
- 공백 중 정상 이동과 재공격 대기 유지, 공격속도가 감속 배율을 바꾸지 않는 처리.

무기별 감속 값은 추후 Excel에서 작성한 데이터 버전을 기준으로 시험한다.

## 대시 순차 충전의 시험 기준

확정한 충전 규칙을 구현한 뒤 다음을 확인한다. 현재는 시험 계획이다.

- 실제 대시 실행마다 1개 차감되고 충전이 0이면 실행되지 않는가.
- 부족한 횟수와 관계없이 충전 타이머 하나만 진행하는가.
- 쿨타임마다 1개씩 회복하고 최대 횟수를 넘지 않는가.
- 추가 사용으로 진행 중인 타이머가 초기화되지 않는가.
- 회복 중에도 남은 충전으로 대시할 수 있는가.
- 최대 횟수에 도달하면 충전이 멈추고 이후 사용 시 새 충전을 시작하는가.

실제 최대 횟수와 충전 시간은 Excel 데이터 버전을 표시해 시험한다.

## 연속 대시 방향의 시험 기준

충전이 남아 있는 조건에서 왼쪽 대시 다음 오른쪽 대시가 가능한지, 다른 방향을 선택한 이후 대시도 기존 충전 소비와 순차 재충전 규칙을 유지하는지 확인한다. 다음 대시 방향이 이전 대시의 방향으로 강제되지 않아야 한다. 대시 예약의 허용 여부와 방향 결정 시점은 후속 규칙 확정 후 시험한다. 현재는 시험 계획이며 구현 또는 실제 시험 완료 기록이 아니다.

## 대시와 기본 공격 독립 실행의 시험 기준

다음은 확정 규칙을 구현한 뒤 확인할 시험 계획이다.

- 공격 준비·판정·후딜 중 대시해도 해당 타격의 시간이 정상 진행되는가.
- 대시 중 공격이 가능한 시점에 시작하고 다음 연격을 연결하는가.
- 공격 예약과 대시 예약이 상대 행동의 실행으로 삭제되지 않는가.
- 같은 시점에 실행 가능한 두 행동이 동시에 진행되는가.
- 왼쪽 대시 중 오른쪽 공격이 가능하고 근접 판정과 투사체 위치 규칙이 유지되는가.
- 공격 중 무기 감속이 대시 이동에 적용되지 않고 대시 종료 후 일반 이동에는 올바르게 적용되는가.
- 대시로 후딜과 연격 공백을 건너뛰거나 초기화하지 않는가.
- 대시 충전 0개에서도 공격은 정상 진행되는가.

현재는 실제 플레이 시험 결과가 아니다. 예약의 개수와 방향 결정 시점, 피격과 강제 예약 폐기는 후속 규칙 확정 후 시험한다.

## 무기별 특수행동과 다수 적 대응의 시험 계획

공격 취소 버튼 없이 무기별 능력을 사용할 수 있는지, 공격형 특수공격과 대시가 서로 중단하지 않고 동시 진행되는지, 판정 범위 내 여러 적에게 피해와 약한 경직을 주는지 확인한다. 서로 다른 무기의 범위와 경직 유지 능력을 비교한다. 특수행동 버튼으로 직접 발동하는 입력을 시험한다. 능력별 세부 입력과 일반 공격의 관계, 보스 저항과 중복 판정은 후속 결정 이후 시험한다. 현재는 실제 시험 결과가 아니다.

## 일반 타격 완료 후 특수행동의 시험 계획

- 준비·판정·후딜 각각에서 특수행동을 입력해도 현재 타격이 취소되거나 후딜이 생략되지 않는지 확인한다.
- 실행 가능한 특수행동 요청이 현재 타격 완료 후 다음 일반 타격보다 먼저 실행되는지 확인한다.
- 일반 공격 버튼을 누르거나 다음 타격을 예약해도 특수행동이 연격 전체 완료까지 밀리지 않는지 확인한다.
- 전환을 기다리는 중에도 대시가 독립적으로 실행되는지 확인한다.

검과 방패·대검·활·단검의 능력 방향으로 비교한다. 실제 능력 종류와 수치는 Excel 데이터 버전에 따른다. 현재는 시험 계획이며 실제 플레이 시험 결과가 아니다.

## 적 강공격의 첫 시험 계획

느린 내려찍기 적 하나로 예고 → 이동·대시 회피 → 공격 후 빈틈 반격 흐름을 확인한다. 현재는 시험 계획이다.

- 준비 자세와 공격 범위 및 실제 판정이 일치하는가.
- 일반 공격의 현재 타격 완료 후 방어·패링을 실행하는 규칙에 맞는 대응 여유가 있는가.
- 대시로 위치를 바꾸면서 공격하고 빈틈에 특수공격을 사용할 수 있는가.
- 일부 정예·보스로 확장할 때 준비 중 경직 저항의 표시를 읽을 수 있는가.
- 피해·밀려남과 다수 적의 강공격이 겹쳐 조작을 장시간 잃는 상황이 생기는가.

실제 수치와 적 목록은 Excel 데이터 버전으로 관리한다. 저항의 상세 방식과 피격 강제 중단 및 예약 폐기는 후속 결정 이후 시험한다.

## 대시 전체 무적과 밀려남 중 공격의 시험 계획

- 대시 시작부터 종료까지 적 공격으로 피해와 밀려남 및 피격 경직이 발생하지 않는지 확인한다.
- 대시 전후에 적 피격이 유효한 상황과 대시 중 무적을 구분한다.
- 공격 준비·판정·후딜 각각에서 적 공격으로 밀려나도 타격이 취소되거나 시간이 초기화되지 않는지 확인한다.
- 근접 판정의 위치가 밀려나는 캐릭터를 따르고 실행 순간 고정한 방향은 유지되는지 확인한다.
- 이미 발사한 투사체가 밀려남과 독립적으로 진행하는지 확인한다.

현재는 시험 계획이다. 밀려나는 중 새 입력·예약과 별도 행동 불능 및 환경 효과는 규칙을 정한 뒤 시험한다.

## 밀려남 중 입력과 대시 탈출의 시험 계획

- 밀려나는 중 새 일반 공격이 가능 시점에 시작하고 현재 타격 중에는 다음 공격 하나만 예약되는가.
- 특수행동 입력이 현재 타격의 후딜 완료를 기다리는가.
- 피격 전에 저장한 공격 예약이 밀려남만으로 삭제되지 않는가.
- 충전이 있으면 대시 입력으로 밀려남이 즉시 종료되고 충전 1개가 차감되는가.
- 충전이 없으면 대시 입력을 저장하지 않고 밀려남이 유지되는가.
- 대시 후 종료한 밀려남이 다시 적용되지 않고 대시 전체 무적과 충전 타이머 유지가 동작하는가.
- 대시 탈출로 공격 후딜과 연격 공백이 생략되지 않는가.
- 일반 이동 입력만으로 밀려남이 즉시 상쇄되지 않는가.

이는 시험 계획이며 실제 구현과 플레이 시험 결과가 아니다. 별도 행동 불능과 사망 및 연속 피격은 후속 결정 이후 시험한다.

## 연속 피격의 밀려남 갱신 시험 계획

- 밀려나는 중 새 유효한 밀려남이 발생하면 현재 위치에서 새 방향·거리·시간으로 갱신되는가.
- 이전 잔여 거리와 시간이 새 밀려남에 합산되지 않는가.
- 반대 방향의 새 밀려남이 발생해도 새 판정의 방향이 적용되는가.
- 갱신 중 일반 공격과 공격형 특수행동의 준비·실행·후딜 및 공격 예약이 유지되는가.
- 밀려남 갱신이 공격 후딜과 연격 공백을 초기화하거나 생략하지 않는가.
- 충전 대시로 갱신된 밀려남을 즉시 종료할 수 있고 종료한 밀려남이 재개되지 않는가.
- 대시 무적으로 무시한 피격이 밀려남을 발생시키거나 갱신하지 않는가.
- 밀려남이 없는 피격에는 갱신 규칙이 적용되지 않는가.

이는 시험 계획이며 실제 구현과 플레이 시험 결과가 아니다. 동일 공격 중복 판정과 피격 후 보호 시간 및 동시 판정 순서는 결정 후 별도 시험을 추가한다.

## 미확정 기획안의 시험 순서

검토안 채택 시 다음 순서로 시험 범위를 구체화한다.

1. [[02 전투/조준과 이동 설계안|조준과 이동 설계안]]과 [[02 전투/회피와 피격 설계안|회피와 피격 설계안]]으로 조작과 취소를 확인한다.
2. [[02 전투/무기 수치와 재장전 설계안|무기 수치와 재장전 설계안]]과 [[02 전투/마나 소비와 회복 수치 설계안|마나 소비와 회복 수치 설계안]] 및 [[02 전투/공격속도 중첩과 상한 설계안|공격속도 중첩과 상한 설계안]]의 기본과 고속 조건을 비교한다.
3. [[03 빌드와 무기/덱과 아이템 슬롯 설계안|덱과 아이템 슬롯 설계안]] 및 [[03 빌드와 무기/태그 집계와 교체 설계안|태그 집계와 교체 설계안]]에서 슬롯과 진입 조건을 확인한다.
4. [[03 빌드와 무기/무기 성장과 대장간 이용 설계안|무기 성장과 대장간 이용 설계안]] 및 [[03 빌드와 무기/신성 성장과 교체 설계안|신성 성장과 교체 설계안]]를 보상에 연결한다.
5. [[01 방향성/던전 분기와 보상 설계안|던전 분기와 보상 설계안]]의 한 스테이지부터 완주 경로를 시험한다.
6. [[04 마을과 성장/런 종료와 영구 해금 설계안|런 종료와 영구 해금 설계안]]의 정산과 이어하기를 확인한다.

측정 기준은 [[04 마을과 성장/훈련장 측정과 시험 범위 설계안|훈련장 측정과 시험 범위 설계안]]에서 관리한다. 이는 실제 플레이 시험 결과가 아니라 다음 검증의 설계안이다.

## v0.21 추가 전투 구조 검증

아래는 미실시 시나리오다. 문서 규칙 결정과 시험 통과를 구분한다.

### U01

- [ ] 물리 직접과 물리 지속에 같은 방어 식, 속성 직접과 지속에 해당 저항만 적용.
- [ ] 혼합 성분이 한 HP 감소 사건으로 합쳐지고 보호·흡혈·동시 후보 비교가 중복되지 않음.
- [ ] 치명타 직접 타격이 유발한 지속 피해에 직접 최종 피해와 치명타가 재적용되지 않음.

### U02

- [ ] 동일 단계 효과의 적용·만료 순서를 바꿔도 최종 능력치가 같음.
- [ ] 강한 감속 종료 뒤 약한 감속이 남은 기간만 적용되고 대시 거리는 유지.
- [ ] 공격속도 스냅샷·충전 정수·퍼센트포인트 연산과 일반 능력치 연산을 혼용하지 않음.

### U03

- [ ] 독·기절이 있는 상태에서 해당 면역 획득 시 제거, 면역 종료 시 복구 없음.
- [ ] 대시 중 독은 유지되고 차단 틱은 소실, 면역과 구별됨.
- [ ] 면역 출처 하나만 만료해도 나머지 출처 유지, 기간 감소는 기존 기간에 소급하지 않음.

### U04

- [ ] 근접 거리 경계·원거리 최소 거리에서 떨림 없이 이동과 공격 전환.
- [ ] 시야 차단 시 최신 위치를 보지 않고 마지막 관측 지점으로 이동하며 벽 우회.
- [ ] 경직으로 준비 취소 시 허가 반환 후 새 예고, 막힌 적 경로는 생성 검사로 검출.

### U05

- [ ] 전후방·각도 경계, 발사자가 이동한 투사체, 폭발 중심 방향을 각각 판정.
- [ ] 발생점 겹침·0속도에서 실행 방향 대체, 무방향 중앙 폭발은 불가 표시.
- [ ] 대시·패링·방어가 겹치면 무적 우선, 성분마다 다른 전방 결과가 생기지 않음.

### U06

- [ ] 한 적과 다수 적 타격의 실제 연격 사이클·공백·대시 무적 시간이 같음.
- [ ] 소리·화면 반응이 대상 수만큼 합산되지 않고 지속 틱이 기본 화면 흔들림을 유발하지 않음.
- [ ] 메뉴·포커스·보상 정지는 기존 규칙으로 시간을 멈추며 일반 충격 연출은 멈추지 않음.

## v0.23 전투 경계 검증

아래 24개 시나리오는 모두 미실시다. 문서 설계 완료를 시험 통과로 표시하지 않는다. 실제 데이터와 구현 후 확인한다.

### U07 동시 피해와 발동 효과의 순서

- [ ] 같은 시각 직접·주기 피해의 후보 입력 순서를 바꿔도 HP 감소·처치 귀속이 같고 직접 후보만 최대 하나를 선택한다.
- [ ] 최초 묶음의 방어력 감소가 같은 묶음의 다른 피해를 바꾸지 않고 다음 발동 묶음부터 반영된다.
- [ ] 상호 치명타·흡혈·처치 소환·추가 피해에서 사망 후 회복과 방 완료 조기 확정이 없고 root 상한 내에 종료된다.

### U08 복수 패링과 발사체 반응

- [ ] 두 근접 공격의 동시 패링은 각 공격 반응과 허가 반환을 한 번씩 적용하되 첫 성공 보상만 발생한다.
- [ ] 비관통·관통 발사체를 패링하면 접촉과 예산을 소비하며 발사자의 새 행동을 원격 중단하지 않는다.
- [ ] 접촉 폭발은 별도 판정을 거치고 대시 중 무시한 접촉은 패링 보상·적 반응을 발생시키지 않는다.

### U09 기절 중 방어 종료

- [ ] 방어 준비·유지·종료 각각에서 기절 시 방어가 남지 않고 기절·종료 시간이 중복 합산되지 않는다.
- [ ] 기절 중 조준·놓기·유지 입력이 방어를 재활성화하지 않고 해제 후 놓기·새 누르기가 필요하다.
- [ ] 기절이 최초 피해 묶음에서 발생해도 같은 묶음의 이미 계산한 전방 방어값을 소급 변경하지 않는다.

### U10 대상 상한과 접촉 소비

- [ ] 이동하는 제한 타격은 판정 수명 전체 상한을 지키고 후속 가까운 대상을 이유로 이전 선택을 바꾸지 않는다.
- [ ] 무적·완전 방어·패링 대상과 동일 대상 재접촉의 상한 소비가 정의와 일치한다.
- [ ] 벽 뒤·출현 중 대상은 후보에서 제외되고 하위 타격/주기 틱별 상한과 root 전체 상한을 함께 적용한다.

### U11 비용 고정과 주기 소비

- [ ] 준비 중 비용 할인 만료·획득과 모으기 수준 변화에도 고정 예약량과 실제 시작 소비량이 같다.
- [ ] 주기 소비와 자연 회복·다른 예약·자동 효과가 겹쳐도 음수 마나와 마지막 무료 주기 효과가 없고 부족 종료 후 자동 재개되지 않는다.
- [ ] 원거리 준비 취소는 장탄을 유지하고 다중 투사체 한 발사 사건은 장탄 한 번만 차감한다.

### U12 효과 출처와 연쇄 수명

- [ ] 중복 카드의 같은 효과는 하나의 부여원 수준이고 다른 부여원은 별도 상태 출처로 구별된다.
- [ ] 같은 출처 재부착은 상태·틱·root를 재시작하지 않고 강한 피해 스냅샷만 적절히 갱신한다.
- [ ] 명시적 주기 발동의 틱에서 root와 깊이를 초기화하지 않으며 관련 객체가 끝난 후에만 기록을 정리한다.

### U13 예고 후 조건 상실

- [ ] 예고 후 사거리 이탈·시야 상실·시야 회복에서 마지막 유효 위치와 현재 준비 추적을 사용해 공격을 마무리한다.
- [ ] 벽 뒤 표적에게 범위를 늘리거나 강제 명중하지 않고 예고·방향 고정·실제 판정이 일치한다.
- [ ] 준비 경직 취소·패링·사망에서 허가를 한 번 반환하고 준비 취소와 실행 빗나감의 쿨타임을 구별한다.

### U14 방 전환과 기술 재지정

- [ ] 재장전 완료·미완료와 마지막 적 처치가 만나는 시각에 실제 장탄만 유지하고 무료 보충이나 탄창 배율 갱신이 없다.
- [ ] 기술 슬롯 교환·카드 제거/재획득·중복 카드 교체가 동일 쿨타임 그룹의 남은 시간을 초기화하지 않는다.
- [ ] 보상 정지·로딩·이어하기 뒤 자원과 유익 상태의 남은 시간이 같고 지난 방 투사체·상태·예약은 새 방에 넘어오지 않는다.
