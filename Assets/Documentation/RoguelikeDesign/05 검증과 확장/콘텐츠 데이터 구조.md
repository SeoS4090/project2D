# 콘텐츠 데이터 구조
## 콘텐츠 구조 설계안

새 카드나 신화권을 추가할 때 기존 연결 규칙을 재사용하도록 무기, 카드, 태그, 장인, 강화와 신성을 분리해 관리한다. 다음 항목은 데이터 항목의 초안이며, 구현 형식은 별도 설계에서 정한다.

| 대상 | 핵심 정보 | 추가할 때 확인할 관계 |
| --- | --- | --- |
| 무기 | 종류, 연격 횟수, 타격별 시간, 종료 공백, 재장전, 태그 | 호환 카드와 강화 후보 |
| 카드 | 효과, 기능 분류, 등장 계층, 태그 | 장착 제한과 발동 조건 |
| 장인과 강화 | 신화 양식, 대상 무기, 조건, 효과 | 기존 카드와 신성의 호환 |
| 신성 | 요구 조건, 권능, 전용 카드, 성장 단계 | 태그 대체 경로와 장인 관계 |
| 영구 해금 | 선행 조건, 비용, 열린 콘텐츠 | 보상 풀과 시작 선택지 |
