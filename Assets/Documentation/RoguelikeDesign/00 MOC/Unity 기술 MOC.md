# Unity 기술 MOC

## 캐릭터 재사용 패키지 — 2026-10-13

[[07 Unity 기술/캐릭터 패키지 분리와 재사용]] — 0.1.0 설치 tgz와 제작 ZIP 생성, 별도 프로젝트 설치·두 Player 빌드·제작 재현 검사 완료. 기존 훈련장 회귀와 나머지 미실시 범위는 해당 문서에서 확인한다.

## 현재 기준과 읽는 순서

Unity 6.3 LTS·URP 2D는 사용자 지정 기준이다. 캐릭터 구조 CH01–CH10 및 종속 기술 T01–T03은 character-1.0에서 규칙을 결정했다. 구현과 실제 시험은 별도다.

1. [[07 Unity 기술/캐릭터 제작과 조립 구조]] — 현재 제작자 조립·플레이어 확장·체형/소켓/가림·저장/실패·측정 계약.
2. [[07 Unity 기술/프레임워크 구조]] — 입력·전투 상태·판정·표현의 책임.
3. [[07 Unity 기술/마네킹 모션 제작과 검증]] — 기존 구현과 실제 과거 시험.
4. [[06 결정과 기록/기획 검토 완료 기록#character-1.0 캐릭터 구조와 종속 기술 질문 종료 — 2026-10-09]] — 질문별 완료 조건과 결정 근거.
5. [[05 검증과 확장/프로토타입 범위와 검증]] — 구현 후 실행할 시험.

현재 후속은 [[06 결정과 기록/기획 진행 현황과 후속 작업]]을 따른다. 새 반례는 [[06 결정과 기록/현재 검토할 기획 질문]]에 등록한다.

## 확정 기준과 검토 범위

사용자 지정: Unity 6.3 LTS `6000.3.18f1`, URP 2D. 게임 규칙 기준은 v0.23의 현재 주제 문서다. 프레임워크 구조는 검토 중이며 project2D에는 훈련장과 1.5등신 마네킹 모션 시험 구현이 있다. 이전 Hero V2 기록도 보존한다. 전체 프레임워크와 새 분리 Prefab 제작의 검증 상태는 아래 기준 문서에서 구분한다.

캐릭터 관련 T01–T03·CH01–CH10은 character-1.0에서 결정했고 완료 기록에서 추적한다. 엔진·렌더러 선택은 열린 질문으로 다시 등록하지 않는다.

## 첫 제작의 사용자 결정 — tech-0.2

첫 제작은 [[07 Unity 기술/훈련장 기반 기술 프로토타입]]으로 한다. 공통 전투 모듈을 사용하는 시험 공간에 허수아비·무기·적·표시·측정 도구를 단계적으로 추가한다. 실제 던전 진행·보상·저장은 별도 통합 검증으로 연결한다. 기존 tech-0.1 구조 추천과 T01–T03 기술 선택은 계속 검토한다.

## 제작자 우선·플레이어 후속 확장 — character-0.2

사용자 결정과 두 진입점의 공통 조립·정책·저장 설계는 [[07 Unity 기술/캐릭터 제작과 조립 구조#제작자 우선과 플레이어 확장 — CH01 결정]]을 따른다. CH01은 [[06 결정과 기록/기획 검토 완료 기록#CH01 제작자 우선과 플레이어 외형 변경 확장]]으로 옮겼다. 플레이어 변경 장소·슬롯·해금·비용은 CH10에서 후속 검토한다. 현재 단계는 문서 설계이며 제작자 도구와 플레이어 UI는 아직 구현하지 않았다.
