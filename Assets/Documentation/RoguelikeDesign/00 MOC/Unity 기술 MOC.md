# Unity 기술 MOC

## 확정 기준과 검토 범위

사용자 지정: Unity 6.3 LTS `6000.3.18f1`, URP 2D. 게임 규칙 기준은 v0.23의 현재 주제 문서다. 프레임워크 구조는 검토 중이며 project2D에는 훈련장과 Hero V2 중간 구현이 있다. 전체 프레임워크와 새 분리 Prefab 제작의 검증 상태는 아래 기준 문서에서 구분한다.

## 첫 제작의 사용자 결정 — tech-0.2

첫 제작은 [[07 Unity 기술/훈련장 기반 기술 프로토타입]]으로 한다. 공통 전투 모듈을 사용하는 시험 공간에 허수아비·무기·적·표시·측정 도구를 단계적으로 추가한다. 실제 던전 진행·보상·저장은 별도 통합 검증으로 연결한다. 기존 tech-0.1 구조 추천과 T01–T03 기술 선택은 계속 검토한다.
