## 진행할 작업

아래 표는 각 작업 명세의 속성을 조회한다. 준비 상태여도 사용자 실행 요청 전에는 작업을 시작하지 않는다. 빈 표는 아직 등록한 작업이 없다는 뜻이다.

```dataview
TABLE task_id AS "ID", task_status AS "상태", priority AS "우선순위", verification AS "검증"
FROM "Assets/Documentation/RoguelikeDesign/08 작업 명세"
WHERE task_status != "완료"
SORT priority ASC, file.name ASC
```

## 검토 및 검증 대기

```dataview
TABLE task_status AS "상태", verification AS "검증"
FROM "Assets/Documentation/RoguelikeDesign/08 작업 명세"
WHERE task_status = "검토" OR verification = "실패"
SORT file.name ASC
```

## 완료 기록

```dataview
TABLE task_id AS "ID", verification AS "검증", updated AS "갱신일"
FROM "Assets/Documentation/RoguelikeDesign/08 작업 명세"
WHERE task_status = "완료"
SORT updated DESC
```

Dataview가 꺼져 있으면 `08 작업 명세` 폴더의 Markdown 속성을 직접 확인한다. 기획 검토 완료와 구현·플레이 검증 완료를 혼동하지 않는다.
