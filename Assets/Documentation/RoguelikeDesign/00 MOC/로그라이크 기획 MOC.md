# 로그라이크 기획 MOC

## v0.23 현재 적용 기준

등록한 전투 구조 질문은 규칙 결정을 완료했다. 실제 게임 구현·Excel 데이터 작성·플레이 검증은 후속 작업이다. [[06 결정과 기록/현재 검토할 기획 질문]]과 [[06 결정과 기록/기획 진행 현황과 후속 작업]]에서 최신 진행 상태를 확인한다.

## 지금 이어갈 기획

기초 전투 규칙을 개발용 상태 전이표와 최소 데이터·프로토타입으로 연결하고 실제 시험을 수행한다. 구체적 후속 범위는 [[06 결정과 기록/기획 진행 현황과 후속 작업]]과 [[05 검증과 확장/프로토타입 범위와 검증]]에서 확인한다. 새로운 구조 질문은 별도 등록한다.
