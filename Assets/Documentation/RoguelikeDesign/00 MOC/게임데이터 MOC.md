# 게임데이터 MOC
수치와 콘텐츠의 다양성은 추후 게임데이터 Excel에서 관리한다. 기획 문서는 동작 규칙과 열의 의미 및 ID 관계를 연결한다.

## 읽는 순서

1. [[05 검증과 확장/Excel과 기획 문서의 연결|Excel과 기획 문서의 연결]]: 관리 책임과 문서 참조 형식.
2. [[05 검증과 확장/게임데이터 열 정의|게임데이터 열 정의]]: 무기, 카드와 태그 및 신성 등 논리 테이블과 열.
3. [[05 검증과 확장/게임데이터 관계와 추가 절차|게임데이터 관계와 추가 절차]]: ID 연결과 새 콘텐츠 추가 및 검증의 흐름.

## 기존 문서와의 연결

- [[05 검증과 확장/콘텐츠 데이터 구조|콘텐츠 데이터 구조]]에서 전체 콘텐츠 관계를 확인한다.
- [[00 MOC/기본 전투 MOC|기본 전투 MOC]]는 공격 시간과 자원 열의 동작을 정의한다.
- [[00 MOC/빌드와 무기 MOC|빌드와 무기 MOC]]는 카드, 태그와 장인 및 신성 참조를 정의한다.
- [[00 MOC/마을과 성장 MOC|마을과 성장 MOC]]는 영구 데이터와 런 정산의 규칙을 정의한다.
- [[기획 진행 현황과 후속 작업|기획 진행 현황과 후속 작업]]에서 규칙 결정과 Excel 작업을 구분한다.

## 현재 상태

Excel에서 수치와 콘텐츠 종류를 관리하는 방향은 채택했다. 구체적인 파일, 시트와 열 및 변환 방식은 설계안이다. 실제 Excel은 아직 작성하지 않았다.
