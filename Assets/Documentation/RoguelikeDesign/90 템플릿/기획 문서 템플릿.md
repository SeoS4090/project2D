# 기획 문서 템플릿
새 문서를 만들 때 이 구조를 복사하고 속성과 본문을 해당 주제에 맞게 바꾼다. 상태는 확정, 설계안, 확장안, 미정 또는 혼합으로 지정한다. 상위 MOC에 새 문서 링크를 추가한다.

## 목적과 방향

이 문서에서 다룰 대상과 플레이어가 경험할 변화를 적는다.

## 확정 사항

채택한 규칙과 적용 조건을 적는다.

## 초기값과 계산 예시

초기값과 설명용 예시를 구분한다. 아직 수치가 없으면 결정 전이라고 표시한다.

## 설계안

검토 중인 방식과 선택 이유를 적는다.

## 미정 사항

후속 논의가 필요한 질문을 적는다.

## 검증 기준

플레이 시험에서 확인할 행동과 결과를 적는다.

## 변경 기록

변경일과 이유 및 영향을 받는 문서를 적는다.

## 게임데이터 참조

이 주제에서 필요한 Excel 논리 테이블과 열을 적는다. 데이터 파일, 행의 고정 ID, 사용 열, 적용 시점, 계산 규칙과 검증 조건을 구분한다. 실제 값과 콘텐츠 목록은 Excel에 두고 문서에는 참조를 남긴다.

속성으로 data_status, data_tables와 data_fields를 사용할 수 있다. 실제 파일이 없으면 작성 예정으로 표시한다.

[[06 결정과 기록/기획 문서 상태와 검토 종료 규칙]]을 따른다. 주제 이름과 상태를 분리하고 design_status와 validation_status를 각각 기록한다. 열린 질문에는 ID·완료 조건·기준 링크를 붙이고, 해결 후 활성 목록에서 완료 기록으로 옮긴다. 과거 제안은 현재 안내와 구분한다.
