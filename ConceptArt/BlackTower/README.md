# 검은 탑 전투 컨셉

2026-10-14 기획서와 세피리아의 탑다운 액션 가독성을 참고해 내장 이미지 생성 도구로 만든 시각 탐색 자료다. Unity 실행 화면이나 구현 완료 에셋이 아니다.

- `black-tower-perspective-study-v1.png`: 최초 분위기 탐색. 낮은 카메라 시점으로 제작돼 탑다운 요구와 맞지 않았던 이전안.
- `black-tower-topdown-v2.png`: 사용자 피드백을 반영한 탑다운 수정안. 후속 시각 검토는 이 이미지를 기준으로 한다.

생성 지시 요약: 검은 탑 내부, 작은 인간 모험가의 대검과 번개 연쇄, 카드 권능 문양, 어두운 석조 바닥과 따뜻한 화로, 읽기 쉬운 적 배치와 픽셀 아트. 수정안은 위에서 내려다보는 정사영 구도, 평행한 바닥 타일, 낮은 벽, HUD 없는 전투 장면을 요청했다. 개별 디자인·효과·게임 규칙의 최종 채택을 의미하지 않는다.
